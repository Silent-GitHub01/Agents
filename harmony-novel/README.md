# 诸子百家小说家 · Harmony Novelist

> 把 50 万字长篇当成软件工程来做的 AI 写作专家：用文件系统固化设定、用流程治理质量、用分工协作提效。

一个 Agent 型 WorkBuddy 专家（内部名「鸿蒙小说家」，当前版本 **v0.1.0**）。它不是「帮你写小说」，而是接管一部长篇从立项到完本的全流程管理：世界观固化、全书大纲与细纲、伏笔追踪与回收预警、逐章创作循环、去 AI 味润色、一致性质检、成本与会话治理。

核心数据来自近百万字的实战验证：单章写作效率提升 3 倍（3 小时 → 1 小时），伏笔回收率 90%+。

## 解决什么问题

长篇创作有四种固定崩坏模式，本专家的全部设计都是针对它们：

| 痛点 | 表现 | 爆发节点 | 对应能力 |
|------|------|---------|---------|
| 记忆丢失 | AI 忘记前文，人设崩坏、世界观打架 | 第 10–15 章 | 设定文档体系 + 会话切换阈值 |
| 上下文过载 | 全文档上传导致卡顿、乱写 | 5 万字+ | 分批上传 + 交接恢复包 |
| 伏笔遗忘 | 第 3 章挖坑第 20 章忘填 | 中后期 | 伏笔表 + 3 章未回收强制预警 |
| 缺乏校对 | 漏洞集中爆发 | 10 万字+ | 一致性质检 A→B 流水线 |

## 四大方法论

| 体系 | 来源 | 解决的问题 |
|------|------|-----------|
| **文学创作方法论** | 《文心》(叶圣陶·夏丏尊) + 6W 原则(莉萨·克龙) | **怎么写好** —— 小说本质论、第三条轨道（欲望 vs 错误信念）、场景卡、主观镜头、语言修炼 |
| **番茄平台实战** | 签约标准 + 编辑 / 金番作者口径 | **能不能签** —— 签约五维评估、防崩四张表、悬念交替、代入感六支柱、数据驱动改文 |
| **AI 协同创作** | AI 写长篇的坑与解法 | **怎么用 AI** —— 四层指令框架、骨架→血肉分步执行、场景节点拆解、章尾钩子三型、约束优先于指令 |
| **角色·反派·结构工程** | Egri + Weiland + Save the Cat + MRU | **骨架怎么搭** —— 角色三维建模、弧线三型（含 OOC 合法突变）、反派动机光谱、15 节拍锚点 |

## 九大核心能力

1. **项目结构搭建** —— 设定文档 / 大纲细纲 / 正文存稿 / 校对报告 / 版本备份五层工作区，UTF-8 TXT 规范
2. **9 技能编辑部体系** —— 总编辑、资料员、剧情策划、写手、质检员、润色师、档案管理员、备份小哥、安全巡检员，一岗一责
3. **全书规划能力** —— 世界观、欲望+错误信念对、顿悟时刻初稿、弧线定档、Save the Cat 节拍锚点、全章细纲、全局伏笔总表、情绪节拍表；规划后**永久锁定**
4. **7 步单章创作循环** —— 资料整理 → 剧情推演 → 正文生成 → 合规审查 → 内容打磨 → 故事线更新 → 自动备份；④→⑤ 为强制质量关卡
5. **每日 5 步续写流程** —— 日更场景的轻量节奏，总耗时约 1 小时
6. **伏笔管理系统** —— 标准伏笔表 + 关系网络表（非对称矩阵）+ 连续 3 章未回收触发预警
7. **去 AI 味·文学润色体系** —— 四层 AI 痕迹识别 → 六门禁检测(Gate A–F) → 三遍去 AI 法 → 五维量化评分（未达 42 分不进下一环）→ 刘震云风格注入
8. **一致性质检 A→B 流水线** —— A 层脚本机械扫描（专有名词漂移 / 禁用句式 / 敏感词）+ B 层多视角对抗式语义复核（OOC / 剧情矛盾 / 时间线 / 伏笔时序）
9. **模型选择与成本管理** —— 按任务类型分配模型档位；另有会话上下文切换阈值与平滑交接恢复包

## 导入 WorkBuddy

**方式一（图形界面，推荐）**

1. 下载本仓库的 `harmony-novel.zip`；
2. 打开 WorkBuddy → 专家中心 → 我的专家 → 导入专家包，选择该 zip；
3. 启用「诸子百家小说家」即可对话使用。

**方式二（手动）**

```bash
# 解压到专家目录
unzip harmony-novel.zip -d ~/.workbuddy/plugins/marketplaces/my-experts/plugins/
```

## 使用铁律

- **规划一次锁定**：全书大纲、世界观、主线走向一经确认即永久锁定，下游环节 100% 遵循，禁止私自修改。
- **质量关卡不可跳**：单章流程 ④ 合规审查 → ⑤ 内容打磨为强制关卡，润色未达五维 42 分不得进入故事线更新。
- **上下文分批**：按「设定 → 大纲 → 正文」顺序分批上传，禁用全量文档一把梭。
- **质检分层**：机械项交 A 层脚本（可复现），语义项交 B 层多视角复核（不靠单次通读）。
