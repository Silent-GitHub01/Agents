## 诸子百家小说家专家

「诸子百家小说家」（内部名「鸿蒙小说家」，Harmony Novelist）是一个 Agent 型 WorkBuddy 专家（长篇小说创作工程师，当前版本 **v0.1.0**）。它不写「一次性文案」，而是把一部 50 万字长篇当成软件工程项目来管理。

核心数据来自近百万字实战验证：**单章写作效率提升 3 倍（3 小时 → 1 小时），伏笔回收率 90%+**。

针对长篇四大崩坏模式（记忆丢失 / 上下文过载 / 伏笔遗忘 / 缺乏校对），专家内置四大方法论：

| 体系 | 来源 | 解决的问题 |
|------|------|-----------|
| **文学创作方法论** | 《文心》(叶圣陶·夏丏尊) + 6W 原则(莉萨·克龙) | **怎么写好** —— 小说本质论、第三条轨道（欲望 vs 错误信念）、场景卡、主观镜头、语言修炼 |
| **番茄平台实战** | 番茄签约标准 + 编辑 / 金番作者口径 | **能不能签** —— 签约五维评估、防崩四张表、悬念交替、代入感六支柱、数据驱动改文 |
| **AI 协同创作** | AI 写长篇的坑与解法 | **怎么用 AI** —— 四层指令框架、骨架→血肉分步执行、场景节点拆解、章尾钩子三型、约束优先于指令 |
| **角色·反派·结构工程** | Egri + Weiland + Save the Cat + MRU | **骨架怎么搭** —— 角色三维建模、弧线三型（含 OOC 合法突变）、反派动机光谱、15 节拍锚点 |

九大核心能力：项目结构搭建 / 9 技能编辑部体系 / 全书规划 / 7 步单章创作循环 / 每日 5 步续写流程 / 伏笔管理系统 / 去 AI 味·文学润色体系（四层识别 → 六门禁 → 三遍去 AI → 五维评分）/ 一致性质检 A→B 流水线 / 模型选择与会话上下文治理。

### 导入 WorkBuddy

1. 下载本仓库的 `harmony-novel.zip`；
2. 打开 WorkBuddy → 专家中心 → 我的专家 → 导入专家包，选择该 zip；
3. 启用「诸子百家小说家」即可对话使用。

### 试试这样问

- 「帮我为一部[题材]小说搭建完整的创作工作流，目标 50 万字，包括设定文档体系、全书大纲细纲、伏笔追踪系统。」
- 「我现在写到第 30 章，请帮我做一轮全面体检：检查伏笔回收情况、人设一致性、前后逻辑矛盾。」
- 「请为我的小说生成第 X 章初稿，约 2500 字，参考附件的设定文档和细纲，注意去 AI 味，保持文风流畅自然。」
