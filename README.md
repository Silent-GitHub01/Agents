> 收录《道德经》历代权威校订本与御注本，并附「翰林编修」古典文献校勘专家，一键完成多版本对齐、经注分离与异文辨析。

本仓库是我自己整理 / 开发的好用工具与资料，当前聚焦《道德经》古籍校注：把传统校雠学方法与现代字符级文本对齐结合，让多版本核校可复现、可沉淀。

## 翰林编修专家

「翰林编修」是一个 Agent 型 WorkBuddy 专家（古籍校勘官，当前版本 **v1.3.0**），核心能力：

1. **底本甄选与重建**：择权威完整之本为底本，繁→简统一、异体折叠，重建干净可比对之底本；
2. **经注分离**：对经注交错之注疏本，以底本为锚做字符级对齐，多守卫自动判定经／注；
3. **多本异文对齐**：逐章字符级对齐（≥3 字相等块并集），异体字折叠后仅留实质差异；
4. **差异分类与避讳核验**：异文／脱文／衍文／章次错位四类；按朝代讳字表核验，以正文实有实例为准、不臆断；
5. **校订本与对比报告**：依统一体例逐章出校订本，并生成 HTML 差异对比报告。

专家内置三系古典校勘方法论（对应 `references/` 下三套卡片库）：

| 体系 | 出处 | 解决的问题 |
|------|------|-----------|
| **陈垣·校法四例** | 《校勘学释例》 | **怎么校** —— 对校／本校／他校／理校，避讳、行款、版本源流、证实层级 |
| **王念孙·理校** | 《读书杂志》 | **怎么断** —— 以声求义、文例互证、失韵校验、改字四闸门、引文甄伪、定案文书 |
| **俞樾·古书通例** | 《古书疑义举例五种》 | **怎么读** —— 对文定诂、倒文、省文、虚词语气、讹误生成链、二阶批判 |

**排查顺序**：句法之怪先疑“己之文法尺度”（走俞樾系），字词之不通先疑“文本有误”（走王念孙系）。

### 导入 WorkBuddy

**方式一（图形界面，推荐）**

1. 下载本仓库的 `hanlin-collator.zip`；
2. 打开 WorkBuddy → 专家中心 → 我的专家 → 导入专家包，选择该 zip；
3. 启用「翰林编修」即可对话使用。

**方式二（手动）**

```bash
# 解压到专家目录
unzip hanlin-collator.zip -d ~/.workbuddy/plugins/marketplaces/my-experts/plugins/
# 注册（需 expert-manager skill 的脚本）
python3 scripts/register_expert.py \
  ~/.workbuddy/plugins/marketplaces/my-experts/plugins/hanlin-collator \
  --session-id <session-id>
```

## 校勘铁律

- **底本须权威且完整**；残缺源本仅充参校，缺章经文据底本补全并于校记注明。
- **避讳须以正文实有实例为准**，不可臆断（如宋「玄→元」、明「元→原」、清「玄→元」正文往往无实例，应归为异文或传本校字）。
- **异体字折叠仅用于比对，绝不改动原文一字**；避讳复原另出复原版。
