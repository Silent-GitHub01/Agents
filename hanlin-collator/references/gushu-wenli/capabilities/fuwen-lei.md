# CAP-05 · 复文（不避繁复／语词叠用复用／连类并称／叙论并行）

## R｜原文

> "古人行文不避繁複。"
> ——俞樾·卷二 第十六「古人行文不避繁複例」

> "古書遇重字，多省不書，但於本字下作二畫識之。"
> ——俞樾·卷一 第十一「以重言釋一言例」（重文記號之由來；误认则生衍文，转 CAP-10）

> "凡雙聲疊韻之字，皆無二義，傳以一字為一義……"
> ——俞樾·卷一（重文與聲韻交界處，與 CAP-07 互見）

> "兩事連類而並稱""兩義傳疑而並存""敘論並行"
> ——俞樾·卷一 第七、八，卷三 第三十八（例名）

## I｜自述

古书里"重复"与"并列"有三种常态，不是衍文也不是啰嗦：

1. **不避繁复**：该重复就重复（如并列诸项均出全书名），后人视为衍文而删，反伤原意。
2. **语词叠用／复用**：同一虚词连用（"之""其""以"等叠见），是语气或句法的需要；见重出虚词先想"复用例"，勿径删（详见 CAP-06）。
3. **两事连类而并称**：本只说一事，因连类而并提另一事（偏举成双），不可据"并称"判定二者同质。
4. **两义传疑而并存**：作者对一事保留两说，并非矛盾或错简。
5. **叙论并行**：叙述与议论交错并行，看似体例不纯，实为古法。

判别要点：**删掉重复后，文本是否更准确**？若不删也通、删了反而损失语气或并列信息，则应判为"复文"而非"衍文"。反之，若两字同义且无语法功能（如"云""有"并列无义），则可能是义同而衍（CAP-10）。

## A1｜书中案例

1. **不避繁复**（卷二·16）：古人叙述中重复用字、重复句式，为其常；旧校据"重复"而删，往往误。
2. **重文作二画**（卷一·11）：古书遇重字多不重书，只在字下加二画（"="）作记号，后人误认作实字或径删，遂致误——这条同时也是 CAP-10「重文作二畫而致誤例」的来源。
3. **两义传疑并存**（卷一·8）：同一事两说并存，作者不删其一，须知此为古书体例。
4. **马叙伦的边界提醒**（p262 前後）：《校录》于俞书"不避繁复"等例下亦有驳正，提示"复"与"衍"的界线须逐条核，不能一概归于复文（详见 CAP-14）。

## A2｜未来触发

**场景：** 读古书见重复字词/重复句，想删以求"简洁"；整理稿里发现并列成分不对称；注家说"此处疑衍"而你想复核；文本中同一事出现两种说法，怀疑是抄误。

**语言信号：** "这里重复了是不是衍文""删掉一个是不是更顺""为什么同一句话说两遍""这两处矛盾哪个对""repetition / redundancy""is this a dittography"

**与相邻能力的分工：** 若重复的两字**同义且无功能** → CAP-10（义同而衍）；若是**虚词**叠用 → CAP-06；若重复源于**重文记号误认**或**旁记字入正文** → CAP-10／CAP-11；本卡处理"作者主动的重复与并列"。

## E｜执行步骤

1. **分类重复对象**：实字重复／虚词重复／整句重复／并列项不对称。完成标准：能指出重复的单位与位置。
2. **测删除后果**：假设删去重复部分，通读并比较——信息是否损失？语气是否改变？并列是否失衡？
3. **查作者体例**：同书他处是否有同样"不避复"的写法（内部一致性检验）。
4. **判型**：不避繁复／语词复用／连类并称／两义并存／叙论并行。
5. **分流**：若删除无害且两字同义 → 转 CAP-10 判衍；若重复来自注文或旁记 → 转 CAP-11。
6. **判停**：无内部旁证时，倾向保留原文（"不删"的默认值），仅记疑。

## B｜边界

- **不适用**：现代文本编辑中的冗余润色；诗歌的修辞重复（属文学分析）。
- **最危险的误用**：以"不避繁复"为护身符，把所有真衍文都放过。俞樾本人的原则是：**先证重复有例，方可保留**；无例可征时仍应怀疑衍文。
- **与衍文的界线**：复文（作者有意）vs 衍文（传写误增）——分界证据：是否有语法/语气功能、是否同义冗余、是否有形近涉上的致误痕迹。
- **"重文致误"的前置排除**：判"重文致误"（CAP-10）之前，须先排除两例——①「以重言释一言」（卷一·11，《诗·有客》"宿宿""信信"是"留宿之久"，非两字各一义）；②「不避繁复」（卷二·16）。三者形似而机制不同，误判即误删。
- **材料边界**：并称、传疑、叙论并行等体例多见于先秦两汉文献，不宜据以评断后世文本。
