# CAP-02 · 对文定诂（上下文异字同义／同字异义）

## R｜原文

> "『有仕於此』之『仕』，即『夫士也』之『士』。『夫士也』正承『有仕於此』而言。『士』正字，『仕』叚字，是上下文用字不同而實同義也。"
> ——俞樾·卷一 第一「上下文異字同義例」

> "……皆由不知古書有同字異義之例也。"
> ——俞樾·卷一 第二「上下文同字異義例」（论《尚书·酒诰》上下两"祀"字，一读为"祀"，一读为"已/止"）

> "古人美惡不嫌同辭，讀者當各依本文體會，未可徒泥其解也。"
> ——俞樾·卷三（美惡同辭例）

## I｜自述

**对文定诂**是古书里最常用、也最容易被今天读者忽略的一条读法：同一段话中相对成文的两处，用字可以（a）不同而义同，（b）相同而义异。

判断方向恰好与常识相反：

- 见**换字**（"有仕於此"↔"夫士也"）→ 不可立刻当换义，先假设同义，因为古人正字与假借字（叚字）混用；
- 见**同字**（"祀茲酒"与"元祀"）→ 不可默认同义，须逐处按上下文定训（一为祭祀，一为止）。

操作要点：先把成对的两句对齐（对文），找出对应位置的字；再看两字的音义关系（同音/双声叠韵/形近/语义相承），最后决定"同义而字异"还是"字同而义异"。这是给没有标点的古书定读的第一把手术刀。

## A1｜书中案例

1. **《孟子·公孙丑》"有仕於此而子悅之……夫士也，亦無王命而私受之於子"**（卷一·1）：旧读以"仕"为出仕之"仕"。"夫士也"正承上句，"士"是正字，"仕"是叚字，两句实同一人——异字而同义。
2. **《论语·卫灵公》"臧文仲其竊位者與？知柳下惠之賢而不與立也"**（卷一·1）：古文"位""立"同字，"不與立"即"不與位"，谓不给俸位，非"不和他一起站立"。
3. **《尚书·酒诰》"朝夕曰祀茲酒，惟天降命，肇我民，惟元祀"**（卷一·2）：上"祀"读为"已（止）"，下"祀"读为"祀"——同字而异义，旧传不知此例，遂失其解。
4. **刘师培补·姚维锐补的边界修订**：姚维锐另立"耦語中異字同義例"，并**特注"此與俞氏上下文異字同義例有別"**——提示同义换字在"耦语（并列双字）"与"上下文对文"两种结构中的成立条件不同。

## A2｜未来触发

**场景：** 读经子遇"两句相对、字面不同"或"同一字两见而语义不合"；为古书加标点时拿不准两处该不该同训；译注中把对文的两字拆成两义（或将同字强行同训）。

**语言信号：** "这两句是不是一个意思""为什么前面说 A 后面说 B""同一个字怎么前后不一样""这句的'士'和上句的'仕'是一回事吗""对文""couplet / parallel phrasing""same word, different sense"

**与相邻能力的分工：** 本卡处理**对文/上下文**层面的同义异义；若两字是**连用成词**（联绵词）而不可拆 → CAP-07；若是**称谓/命名**转换 → CAP-08；若两字义相反而一字兼有（美恶同辞）→ CAP-09。

## E｜执行步骤

1. **对齐对文**：找出成对的两句（或同段两处），列出对应位置的字。完成标准：能画出"甲句第 n 字 ↔ 乙句第 m 字"的对应。
2. **判关系类型**：字形不同而音近/义近 → 走"异字同义"；字完全相同 → 走"同字异义"。
3. **异字同义的验证**：查两字是否有古今字/正叚字/双声叠韵关系（可查《说文》《广韵》及旧注），并以同书他处的同类用法互证。完成标准：至少给出一条旁证。
4. **同字异义的验证**：逐处按上下文定训，并说明若统一训释会产生什么荒谬结果（反证）。
5. **判停**：若两字既非同义关系、也无法证明同字异义，则回到 CAP-01 分流（可能是讹误或后人误解）。

## B｜边界

- **不适用**：非对文结构的孤立字词训释（此时对文无从对齐）；纯词汇史查询。
- **反场景**：把"对文必同义"绝对化——对文句中确有真换义（如反义对举）与本非同源者；俞樾此例旨在提供**优先假设**，不是铁律。
- **常见误用**：以异字同义为由，把本当分训的两字强行合训；或反之，据同字异义滥改旧注。马叙伦《校录》对俞书中"同字异义"类条目的套用范围就有所纠弹（参照 CAP-14）。
- **越过本卡的情形**：若发现是注文混入正文（正文突兀、注文可通）→ CAP-11；若是后人加偏旁致字变 → CAP-13。
