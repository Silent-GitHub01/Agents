# 决策规则速查 — 古书疑义举例五种（俞樾《古书疑义举例》＋刘师培补、杨树达续补、马叙伦校录、姚维锐增补）

| 能力 | 一句话规则 |
|---|---|
| 读不通分流总纲（误读≠误文） | 句法之怪先查文例（先疑己之文法尺度），字词之不通再查文本；两路走完才议改字。 |
| 对文定诂（上下文异字同义／同字异义） | 见换字先假设同义（正字/叚字），见同字须逐处定训——对文先合后分。 |
| 倒文（倒句／倒序／错综成文／参互见义／举此见彼） | 先测韵、再试顺、找同行；判倒文必须给出倒置后的确切读法。 |
| 省文（蒙上省／探下省／疏略／前后省／省曰字） | 判省文必须指出所省之字见于上文或下文；无来源的缺字才是脱文。 |
| 复文（不避繁复／语词叠用复用／连类并称／叙论并行） | 先证重复有例，方可保留；删除后信息不损且两字同义者，才转判衍文。 |
| 语气与虚词（语急语缓／也邪／虽唯／助语用不／发端连及之词） | 虚词按实词解则句梗，按语气解则意顺；否定词读作语助风险极高，须另有旁证。 |
| 声韵与联绵字（双声叠韵／读若／连用不得分训／叶韵古读） | 双声叠韵连用之字不得分训；叶韵须依古读，不得据今音改字。 |
| 称谓与名实（称谓／寓名／大名小名互代／以质表物／同名异实） | 先问该名指人还是指物、是本名还是代称、是一人还是两人。 |
| 词义活用与褒贬（实字活用／美恶同辞／高下相形／施受同辞／虚数不可实指） | 先问是活用、兼义，还是旧注误会——一字可兼褒贬与相反二义。 |
| 衍文生成（义同／形似／涉上下文／涉注文／重文／因衍而误删误倒） | 先归因（义同/形似/涉上下文/涉注/重文），后删字；无归因的删除等于臆改。 |
| 注疏层陷阱（涉注文而误／以注说改正文／以旁记字入正文） | 正文突兀而注文可通者，先疑旁记字与注文混入正文，先分层再校字。 |
| 错乱之形（误夺误补／误字误改／一字二字／空围／上下互误易置／简策错乱） | 用"形"反推"因"——错乱形态须能对应书写与装帧方式，方可信。 |
| 误解与妄改（不识古字／不达古语／两字一义／据他书／分章分篇／误增不字／传述异同） | 先定"作案人"（传写者还是后人/注家），未经甄别的引文与他书异文不得改字。 |
| 二阶批判（例须受检／套例之弊／判停条件） | 立例不等于定案；竞争性归类无法排除时两存待考，不得单取其一。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
