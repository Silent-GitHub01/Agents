## 1. 结构 (Structural)

### 类型
方法论类型学（"例"的归纳汇编）：以经子实例立"例"，每例一个命名规律 + 若干书证。

### 一句话主旨
古书自有一套用字与行文的通例，执后世（唐宋以降）文法去读周秦两汉之书，会把"古人本来如此"误判为"传写讹误"；读书须先"习知其例"，再谈校改。

**俞书七卷两层（梁启超的划分，本 skill 的核心骨架）**：

- **卷一—卷四＝"古代文法书"（读法层）**
  - 卷一（1–14）用字句法之变：上下文异字同义／同字异义、倒句、倒序、错综成文、参互见义、两事连类并称、两义传疑并存、两语似平实侧、两句似异实同、以重言释一言、一字作两读、倒文协韵、变文协韵
  - 卷二（15–26）繁省与语气：不嫌疏略、不避繁复、语急、语缓、加曰字／省曰字、文具于前略于后、文没于前见于后、蒙上省、探下省、举此见彼、因此及彼
  - 卷三（27–39）传述与称谓名实：传述异同、引书增减、称谓、寓名、大名冠小名／代小名／小名代大名、双声叠韵代本字、读若字代本字、美恶同辞、高下相形、叙论并行、实字活用
  - 卷四（40–51）虚词：语词叠用、复用、句中用虚字、上下文变换虚字、反言省乎字、助语用不字、也邪通用、虽唯通用、句尾用故字、句首用焉字、发端之词、连及之词
- **卷五—卷七＝"校勘秘诀"（讹误层）**
  - 卷五（52–68）衍／脱／误／改的生成机制：义同而衍、形似而衍、涉上下文而衍、涉注文而衍、涉注文而误、以注说改正文、以旁记字入正文、因误衍而误删／误倒、因误夺而误补、因误字而误改、一字误为二字、二字误为一字、重文作二画、重文不省、阙字作空围、本无阙文而误加空围
  - 卷六（69–74）错乱之形：上下两句互误、上下两句易置、字以两句相连而误叠／误脱、字句错乱、简策错乱
  - 卷七（75–88）识读之误与后人妄改：不识古字而误改、不达古语而误解、两字一义而误解、两字对文而误解、文随义变而加偏旁、字因上下相涉而加偏旁、两字平列而误倒、两文疑复而误删、据他书而误改、据他书而误解、分章错误、分篇错误、误读夫字、误增不字

**论点之间的关系**：递进＋互补——(1) 阅赛层（读法）→ (2) 讹误层（校法）→ (3) 四家补正（训诂/修辞/声韵）→ (4) 马叙伦二阶驳正（例本身也须受检）。

### 作者要解决的核心问题
周秦两汉之书"用词造句与后世多有不同、抄传刊刻多有讹误、音义变易多有歧异"，后人读不懂就妄改、妄解；俞樾要"使童蒙之子习知其例，有所据依"——先给人一张"古书本来长什么样"的清单。

## 2. 解释 (Interpretive)

### 关键术语（作者本人的用法）

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 例 | 一条被命名、可举证的古人行文/用字/致误规律 | 不是"例子"，是"规则条款" |
| 上下文异字同义 | 同一段内换字而义同（"有仕於此"／"夫士也"） | 常识以为换字即换义 |
| 上下文同字异义 | 同字在此处是"有"，在彼处是"又" | 常识以为同字必同义 |
| 倒句／倒字 | 俞：整句语序颠倒；马叙伦：多为一字倒置（倒字），非句子倒装 | 二者边界是本书记载最激烈的方法争论 |
| 正字／叚字 | 叚＝假借字（如"士"正、"仕"叚） | "正"不等于"对"，只是本字 |
| 涉注文而误 | 错误来自双行小注混入正文 | 常识只看正文传写，不看注疏层 |
| 以旁记字入正文 | 读者旁注校字被刻工刻进正文 | 与"衍文"不同：衍文无来源，旁记有来源 |
| 蒙上文而省／探下文而省 | 省略的原因在上下文（承前省/启后省） | 常识把省略当脱文 |
| 语急／语缓 | 说话快则省字、说话慢则加字 | 是"语气"而非"语法"导致的字面差异 |
| 美恶同辞 | 同一字兼有褒贬两面（"苦，快也"） | 常识以为一字一义 |
| 不识古字而误改／不达古义而误解 | 后人因不识古字、不懂古义而擅改/误读 | 与"传写之误"形成对照：一是无心，一是无知 |

### 核心命题（用自己的话）

1. **误读≠误文**：读不通时，先怀疑自己的文法尺度，再怀疑文本——顺序与本能相反。
2. **古书之"怪"多半有例可循**：换字、颠倒、省略、加字、叠字，多是惯例而非错误。
3. **讹误有生成链**：衍→删、衍→倒、夺→补、字误→连改、注文→入正文；一处误可繁殖多处。
4. **注疏层是次生错误的温床**：以注说改正文、旁记字入正文、涉注文而衍/误。
5. **"据他书"是危险动作**：据他书而误改／误解，专讲他校的陷阱。
6. **例须受检**：马叙伦的校录证明"例"会套错（倒字≠倒句），立例不等于定案；刘师培少年之作"析句未精"亦被后人点名。

### 论证链
以经子原句为证据 → 指出旧注/通行读法的错误 → 立一条"例"并命名 → 用数例互证（"句法正同"、"亦同此例"） → 由例反推某处当读作某。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 材料只到清代通行本与旧注，未见出土简帛（银雀山、马王堆、清华简可验证/推翻部分读法）；如"两字义同而衍"在简本中或本不衍。
- 立例极重"无字处"之意，缺形式化标准：同一现象可归两例（倒字/倒句、义同而衍/形似而衍），分类互斥性弱。
- 以"童蒙"为对象，重举例轻体系；88 例无层级、无索引，实用时须重建结构。

### 作者的立场盲点
- 俞樾本人亦不免"理校"臆改（马叙伦校录即抓其"倒句例"套用过宽、"野于饮食"等例取证不足）。
- 训诂依赖旧注与声韵，但清代古音学结论今有修正（刘补"双声叠韵连用不可分训"的边界，姚氏又补"有双声之字连用不得分为义例"——正是对边界的再收紧）。
- 默认"古书愈古愈简、愈简愈真"，对文本流传的复杂性（多源、并行、改写）估计不足。

### 未被证明的假设
- 假设存在统一的"古人行文之例"，且可跨书、跨文体通用（实际例的适用范围随文体/年代而变）。
- 假设"例"具有解释力即可用作改字依据（此点由 dushu-lizheng 的"例不是证"铁律化解）。

### 最强反对意见
"例"是事后归纳的描述性概括，不是可证伪的规则；把读不通的句子归入某"例"，等于用命名回避解释。且例目互相重叠、边界由直觉划定，容易被滥用为"凡不通皆可称例"——马叙伦、洪诚（评刘补"少年之作，析句未精"）已从内部提出此类批评。

> 以上批判直接成为下游能力卡 B（Boundary）字段的来源。

## 4. 应用潜力 (Applicability)

### 可 skill 化的内容
- [ ] 入口：读不通时的分流判断（是文例？是误解？是讹误？）——"误读≠误文"三问
- [ ] 用字层：上下文异字同义/同字异义（对文定诂）
- [ ] 句法层：倒文类（倒句/倒序/错综/两字平列而误倒）——含"倒字≠倒句"的辨析
- [ ] 省文类：蒙上省/探下省/疏略/前后省/省曰字
- [ ] 复文类：不避重复/语词叠用/连类并称/举此见彼/因此及彼
- [ ] 虚词层：语急语缓、也邪通用、虽唯通用、助语用不/无、句首焉、句尾故、发端词、连及词
- [ ] 声韵层：双声叠韵代本字、读若字代本字、连用双声叠韵不可分训、句中用韵/叶韵误读
- [ ] 称谓名实层：称谓、寓名、大名小名互代、举偏该全、以母名子、两名错举
- [ ] 词义活用层：实字活用、美恶同辞、高下相形、二义相反一字兼具、施受同辞、虚数不可实指
- [ ] 讹误生成链：衍（义同/形似/涉上下/涉注/重文）→ 删；夺 → 补；误字 → 改；连锁
- [ ] 注疏层错误：涉注文、以注说改正文、旁记字入正文
- [ ] 错乱层：上下两句互误/易置、相连误叠/误脱、字句错乱、简策错乱
- [ ] 误解类型学：不识古字、不达古义、两字一义、两字对文、据他书误改/误解、分章分篇、误读夫字、误增不字
- [ ] 传述与引用层：传述异同、引书增减、避讳删改、以后称前
- [ ] 二阶批判：马叙伦式"例的适用性检验"（例须受检、套例会错）

### 不适合 skill 化的内容
- 对每个"例"的逐条书证考订（作为 A1 案例素材保留，不独立成卡）
- 单纯的字词释义、经义诠释（不属本 skill 边界）

### 预估 skill 数量
**约 13–16 张能力卡**（single 模式：1 入口 + 12–15 卡），最终由阶段 1.5 三重验证决定。

### 优先级排序（按"最能赋能普通人"）
1. 入口分流卡：读不通先查文例（误读≠误文）+ 何时该转向校勘
2. 用字/对文卡：异字同义、同字异义（最高频的"读不懂"来源）
3. 衍脱误倒的生成链卡（校记写作的骨架）
4. 注疏层错误卡（古籍整理的隐蔽杀手）
5. 虚词卡（句读与语气，现代读者最易误断）
6. 二阶批判卡（例须受检，防止套例滥用）
