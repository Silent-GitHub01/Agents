# GLOSSARY — 《古书疑义举例五种》共享术语词典

> 供下游能力卡与读者共用。术语分三类：**本书自创的"例名"**（A）、**方法论概念**（B）、**易混术语辨析**（C）。
> 出处标注：俞＝俞樾《古书疑义举例》（卷·例号）；刘＝刘师培《补》；杨＝杨树达《续补》；马＝马叙伦《校录》；姚＝姚维锐《增补》。

## B 类 · 方法论概念（先掌握这些，才看得懂"例名"）

| 术语 | 定义 | 备注 |
|---|---|---|
| 例 | 一条被命名、可举证的古人行文/用字/致误规律条款 | **不是"例子"**；本书的元术语 |
| 正字 | 本字（依字形本义） | 与"叚字"相对 |
| 叚字 | 假借字（借同音字代本字） | "士"正、"仕"叚 |
| 读若／读为 | 注音兼明假借关系的术语 | "读为"多用于破假借 |
| 双声／叠韵 | 两字声母相同／韵部相同 | 联绵字成词方式 |
| 耦语 | 并列成对的双字结构（对文） | 姚补立"耦语中异字同义例" |
| 对文／连文 | 相对成文的两句／连用的两字 | 定诂的两个基本结构 |
| 语助（助语） | 只表语气、无实义的虚字 | 不成词时加助语配词 |
| 发端之词／连及之词 | 句首起下之词／连类而及之词 | 俞·卷四 50、51 |
| 空围 | 古书用以标示阙文的方框（□） | 有"本无阙文而误加空围"之弊 |
| 错简／简策错乱 | 简的编连次序错乱 | 表现为段落突兀跳接 |
| 旁记字 | 读者/校者旁注的异文校字 | 易被刻工刻入正文 |
| 注文 | 双行小注等注释文字 | 与正文层须分开处理 |
| 夺／脱 | 少字 | "因误夺而误补" |
| 衍 | 多字 | 有五种生成机制，见 CAP-10 |
| 倒／乙 | 字序颠倒／乙正 | "倒字"与"倒句"须辨 |
| 分训 | 把连用/对文字拆成两义分别训释 | 望文生训的主要形式 |
| 望文生训 | 据字面曲解，不顾古义 | 刘补核心批评对象 |
| 以今律古 | 用后世文法/字义/音读衡量古书 | 俞樾序所斥 |
| 传写之误 | 抄刻过程的无心之失 | 与"后人之失"相对 |
| 小人儒之失 | 指后人不知而强作解人 | 即"不识古字而误改" |
| 名动相因 | 器物之名兼作"用之之词"（用该器物的动作） | 刘补·4；判名／动以**句式**为准，不以语感为断 |
| 同义浅深 | 两字同义而程度有别（"饥"与"饿"） | 口诀："对文则别，散言则通" |
| 结语词 | 章末／篇末惯用的收束语（"……也""是以……也""夫是之謂……"） | 编次复原的内证之一 |
| 标题句 | 章首独立的名词短语，与上下文不属 | 多为**章题误入正文**（杨续补「文中有标题例」） |
| 四层分层 | 正文／注文／校记（旁记）／标题 四层 | 注疏层问题的标准处理序：先分层，再校字 |
| 引文甄伪 | 判断他书引文可否作证据（节引？意引？避讳删改？同源？） | **他书可作旁证，不可作主证** |

## A 类 · 俞樾 88 例（按七卷两层）

### 卷一（1–14）用字与句法之变
上下文异字同义｜上下文同字异义｜倒句｜倒序｜错综成文｜参互见义｜两事连类而并称｜两义传疑而并存｜两语似平而实侧｜两句似异而实同｜以重言释一言｜以一字作两读｜倒文协韵｜变文协韵

### 卷二（15–26）繁省与语气
古人行文不嫌疏略｜古人行文不避繁复｜语急｜语缓｜一人之辞而加曰字｜两人之辞而省曰字｜文具于前而略于后｜文没于前而见于后｜蒙上文而省｜探下文而省｜举此以见彼｜因此以及彼

### 卷三（27–39）传述、称谓与名实
古书传述亦有异同｜古人引书每有增减｜称谓｜寓名｜以大名冠小名｜以大名代小名｜以小名代大名｜以双声叠韵字代本字｜以读若字代本字｜美恶同辞｜高下相形｜叙论并行｜实字活用

### 卷四（40–51）虚词
语词叠用｜语词复用｜句中用虚字｜上下文变换虚字｜反言省乎字｜助语用不字｜也邪通用｜虽唯通用｜句尾用故字｜句首用焉字｜古书发端之词｜古书连及之词

### 卷五（52–68）衍脱误改的生成
两字义同而衍｜两字形似而衍｜涉上下文而衍｜涉注文而衍｜涉注文而误｜以注说改正文｜以旁记字入正文｜因误衍而误删｜因误衍而误倒｜因误夺而误补｜因误字而误改｜一字误为二字｜二字误为一字｜重文作二画而致误｜重文不省而致误｜阙字作空围而致误｜本无阙文而误加空围

### 卷六（69–74）错乱之形
上下两句互误｜上下两句易置｜字以两句相连而误叠｜字以两句相连而误脱｜字句错乱｜简策错乱

### 卷七（75–88）识读之误与后人妄改
不识古字而误改｜不达古语而误解｜两字一义而误解｜两字对文而误解｜文随义变而加偏旁｜字因上下相涉而加偏旁｜两字平列而误倒｜两文疑复而误删｜据他书而误改｜据他书而误解｜分章错误｜分篇错误｜误读夫字｜误增不字

## A 类 · 四家补例

**刘师培《补》11 条**（目录 p166–167，序与正文 p168–192）——补训诂/词例：
两字並列係雙聲疊韻之字而後人分析解之（1，「詭隨」）｜兩字並列均為表象之詞而後人望文生訓（2，p169–171，「窈窕」「蛾眉」）｜二義相反而一字之中兼具其義（3，p171，「苦，快也」）｜使用器物之詞同於器物之名（4，p174）｜虛數不可實指（「九合諸侯」等，p185–186）｜舉偏以該全｜同義之字並用而義分深淺（10，p189）｜倒文以成句（p186–187）｜末數條論《助字辨略》類虛詞（p190–192）。

**杨树达《续补》26 条**（目录 p193，题名页 p194，正文 p195–256；分二卷即卷上/卷下）：
一事互存二說以徵實｜**文中有標題**（p218–219：《荀子》「扁善之度」「治氣養心之術」「大儒之效」）｜**以製物之質表物**（p195：「以鐵耕乎」）｜誤讀問答之辭｜以後稱前｜避重複而變文｜引傳記以忌諱而刪改｜**據古人當時語氣直述**（p203：「期期」口吃實錄）｜一人之語未竟而他人插語（p201）｜施受同辭（p200）｜二字之名省稱一字｜人姓名之間加助字（p195）｜「自」作「雖」義用｜「者」作「然」義用｜**以母名子**｜**兩名錯舉**（p249）｜「所」作「意」義用｜兩語分承上文｜倒句｜省句｜起下之詞｜文中自注｜大夫稱人｜記言省「曰」字｜「于」作「以」義用｜「之」「其」通用；另附「名或同號而其人異」（p245）、「省名」（p197）之說。

**姚维锐《增补》15 条**（目录 p282–283，正文 p284–310）：
耦語中異字同義（1，自注「與俞氏上下文異字同義例有別」，p284）｜一字不成詞則加助語｜有草木鳥獸同名｜有葉韻之字而後人誤讀（p290：「無偏無頗」被唐玄宗改作「陂」）｜二聲相近二義相通而字亦相通｜形相似聲相近而義亦相通（p296：「蕉/焦」）｜有雙聲之字連用不得分為義｜有疊韻之字連用不得分為義（p297–298）｜補美惡同辭（14，p308）｜補句中用虛字（15，p309）等。

**马叙伦《校录》**（无自身例号，逐条编号勘正俞书，含驳正）：以「敘倫案」形式指出俞书套例之误（最著名者为「所舉皆倒字，非倒句」），并示范**校记体例**——逐条编号、先录原说后下己断、多证并列、异文全录、存疑不武断。详见 CAP-14。

## C 类 · 易混辨析

| 易混对 | 分辨标准 |
|---|---|
| 倒句 vs 倒字 | 整句语序倒装 vs 单字错位；马叙伦指俞书所举多为后者 |
| 省文 vs 脱文 | 所省之字见于上下文 vs 无来源的缺字 |
| 复文 vs 衍文 | 作者主动重复（有语法/语气功能）vs 传写误增（同义冗余） |
| 联绵字不可拆 vs 同字可兼义 | 双声叠韵连用成词（禁拆）vs 同一字兼有褒贬/相反二义（可兼） |
| 传写之误 vs 后人之失 | 无心之失（复原）vs 无知/有意之误（撤销） |
| 文例 vs 讹误 | 古人常态（不改）vs 传写变坏（可复原） |
| 据他书改 vs 他校取证 | 无甄别径改（禁）vs 证同源、辨优劣后使用（可为证据） |
| 美恶同辞 vs 分训 | 一字兼褒贬（合法）vs 联绵词被拆（违法） |
| 形似声近 vs 改字依据 | 解释工具（解释古书为何互用）vs 改字许可（须另附旧注／他书／异体第二证） |
| 口吃重言 vs 误叠 | 史家据当时语气直述（实录，不动）vs 传写误增（可删） |
| 标题句／结语词 vs 随意重排 | 具多重内证的编次复原 vs 见读不顺即重排（禁；先调字序，再句序，最后段序） |
