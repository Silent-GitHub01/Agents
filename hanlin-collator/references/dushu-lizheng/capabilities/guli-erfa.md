# 古历二法（数字历法须核古制，不得以今法改古）

## R 原文

「正月指寅，十一月指子，一歲而帀，終而復始。指寅者，《顓頊曆》所起也，至丑而一帀。指子者，《殷曆》所起也，至亥而一帀。故指寅、指子皆一歲而帀，且『子』與『始』爲韻。後人改『十一月指子』爲『十二月指丑』，則既失其義，而又失其韻矣。」（约第16099行，讀淮南子雜志書後·天文）

## I 自述

本卡是数字/历法校勘的专精窄域。先秦两汉历法并非只有一种：建寅（《顓頊历》）与建子（《殷历》）二法并存——同一"一岁而帀"，在不同历法里起算点不同（指寅 / 指子），结论却都成立。汉初节气次序也与今《农历》不同（如惊蛰本在雨水之前）。

后人不知古历有二法，辄以《太初历》《月令》等后起今法去"修正"古书数字，结果既失其义又失其韵。凡古书中的星度、节气、爵秩员额等数字，校勘时须先还原其所依古制与他书，不得以今法、今算改古。

## A1 书中案例

1. **淮南·天文「十一月指子」改"十二月指丑"**（约第16099行）：原文"正月指寅，十一月指子"是《顓頊历》（指寅）与《殷历》（指子）二法并存之证，且"子"与"始"为韵。后人以今法误改"十一月指子"为"十二月指丑"，义韵两失。念孫据二法并存还原原貌。→ 古历二法直接推翻今法妄改。

2. **淮南·天文 惊蛰/雨水次序**（CP-29 验证）：汉初"惊蛰"本在"雨水"之前，今本次序在后，乃后人以今《月令》节气次序改古。校者须以案时不案今。→ 节气次序随古制，非讹。

3. **漢書 爵秩员额数字**（CP-29 验证）：外戚/元后传中爵秩员额数字涉上下文而误，须核《漢紀》《表》《志》及礼制，不得以今制推算"纠正"。→ 数字误须依古制与他书，非依今算。

## A2 未来触发

**场景**：校古书历谱、节气、星度、朔闰、爵秩员额、度量数字；用户说"这节气次序不对/这数字算下来矛盾/汉代不该这么排"；拿到按今《农历》"理顺"的古历文本。

**语言信号（中英）**：
- 中文："节气次序不对""这数字算不通""汉代历法""按今农历改""星度/朔闰/员额"
- 英文："calendar order wrong / number doesn't add up / Han calendar / emend per modern almanac / 古历 二法 建寅 建子"

**与相邻能力区分（初稿）**：本卡仅管数字/历法/节气/度量；普通文字讹误转 `wenli-huzheng` 文例互证或 `shiyun-xiaoyan` 失韵；"以今法改古"与 `yijin-lügu` 不据彼改此 共享"不得以今律古"精神，但本卡维度是历法专精、彼卡维度是他书/俗本妄改。

## E 执行步骤（本卡自足，窄域专用）

1. **判维度**：确认故障点是历法/节气/星度/朔闰/爵秩员额/度量等数字，而非普通文句。完成标准：归类到"古历数字"域。
2. **查古制**：问"这是哪种古制？建寅还是建子？汉初还是太初后？"以作者时代历法为准（汉初惊蛰在雨水前）。完成标准：给出所依历法名称与起算。
3. **核数字**：以《汉纪》《表》《志》、本书他篇、礼制互校；凡与今制不同者先假定为古制遗存，非讹。完成标准：列出古制依据，排除"今算不符即误"。
4. **判停**：确有异文/形近/涉上下文而误的硬证方可改；否则保持古貌，存疑。完成标准：改动须有古制或善本证据，否则标记待校。

## B 边界

- **窄域适用**：仅适用于数字/历法/节气/度量爵秩；普通文字讹误、对文失儷、失韵等勿套用本卡，转对应能力。
- **"古书偶有不整齐"边界**：不可因数字不合今算就擅改——王氏明言古历有二法，同一现象可有两解；今人认为"错"的，常是未达古制。
- **失败模式**：以《太初历》《月令》今法"修正"汉初古历（如指子→指丑）；以今节气次序重置古书（惊蛰/雨水）；以今官制推算古爵秩员额。
- **阶段0批判所得边界**：普通人极易觉"数字明显错"而动手，正是王氏所讥"取不误之文而妄改之"；数字证据须与他证收敛，孤"今算不符"不动手。
