# 后人妄改七型与追改层位归档

## R 原文

「其已改者則有《漢書》《漢紀》……其已改而舊迹尚存者則有《周本紀》《逸周書》《説苑》……其未改者則有《殷本紀》《齊世家》《留侯世家》及《管子》《吕覽》《淮南》《新序》……其引《史記》而已改者則有《樂記》正義……其未改者則有《武成》正義、《羣書治要》。」（约第1758行，史記·周本紀·散鹿臺之錢）

「後人見《王制》有『被髮文身』之語，遂改『劗』爲『被』，并注中『劗』字而改之。」（约第13228行，淮南·原道·被髮文身）

## I 自述

确认一处文字是"后人追改"之后，真正难的不是"它该作什么"，而是"这一改从哪来、改于何时、在群书中活成了什么样子"。本卡给两套可操作工具。

**第一套·妄改七型**：把每一次追改按动机/依据归类——不识古字而改、以意改、依晚出书改、依他篇他传改、为弥缝句读而改、注家不通而改正文或注文、以常见字改罕见字。七型不是装饰标签，它逼你说出"改者手头拿着哪本书、心里想着哪句常语"，坐实改字依据。

**第二套·层位归档**：同一讹字在本书他篇、同系统他书、类书古注里是否还留着旧字，决定证据怎么摆。按"改字痕迹存活度"分三栏（已改者／已改而旧迹尚存者／未改者），引文再分两档（引而已改者／引而未改者），合为五档。未改处越多、分布越广，越证旧字是原貌。

本卡管**空间层位**（同一讹字在各处的存活分布）与**追改源头定位**；它与 CAP-03（定性"这是传写还是妄改"）和 CAP-13（时间链上的错误繁殖序）垂直分工——CAP-03 答"哪一半"，CAP-13 追"沿时间怎么传"，本卡答"在空间上活在哪里、从哪本书起头"。

## A1 书中案例

1. **史记·周本纪「散鹿臺之錢」遍改为「財」**（约第1758行）：晚出《古文尚書·武成》作"散鹿臺之財"行世后，学者习闻其语，遍改古书。念孫以十证分五档——已改者（《漢書》《漢紀》）、已改而舊迹尚存者（《周本紀》《逸周書》《説苑》残存"錢"）、未改者（《殷本紀》《齊世家》《留侯世家》及《管子》《吕覽》《淮南》《新序》皆作"錢"）、引而已改者（《樂記》正義）、引而未改者（《武成》正義、《羣書治要》）。→ 未改处遍布群书且唐初治要仍作"錢"，坐实"財"为后改。→ 结果：定原作"錢"，并据未改处分布反推改风起于晚出《尚書》盛行之后。

2. **淮南·原道「劗髮」依《王制》改「被髮」**（约第13228行）：高注"被，翦也"于训无征；念孫据《漢書·嚴助傳》"越人劗髮"、晋灼引《淮南》"越人劗髮"、《逸周書》"鬋髮"、《墨子》"翦髮"证本作"劗"（翦也）。后人见《王制》有"被髮文身"常语，遂改"劗"为"被"并改注中"劗"字；且《趙策》俗本亦改"翦髮"为"被髮"。→ 属"依晚出书改"＋"不识古字"两型叠用；注文被连带改从误本，反成铁证。→ 结果：复原"劗髮"。

3. **殷本纪「炮格」被群书改为「炮烙」**（约第1753行）：段玉裁、念孫据《韓子·喻老》"設炮格"、《吕氏春秋》"肉圃爲格"高注、《索隱》引鄒誕生音"格"证本作"炮格"。后人因"炮烙"常语通行，竟将《史記》《漢書》《荀子》注诸书尽改作"炮烙"。→ 属"以常见字改罕见字"＋"依俗本"型；群书一致反证其错已繁殖。→ 结果：定"格"不误，"烙"为后改。

## A2 未来触发

当用户面对以下情境时启用：
- 已定性为"凭意妄改"（经 CAP-03 闸门），还需进一步定位"这改起于哪本书、改于什么时代、在群书里活成了几档"。
- 同一字在多处所见不同（甲书作 A、乙书作 B、类书又作 A），要据此判断哪个是原本、改风从何而起。
- 想用"大家都这么写"当正确性论据，或见整理本"据某书/某本"改动，需反向测序其追改源头。
- 改一字后须连带改注文才通（强解红旗），要归入"注家不通而改"型并定位误本。
- 定案只答了"原文当作某"、答不出"今本何以成此"，需补第二问以防改字仍有风险。

**语言信号（中英 key triggers）**：
- 中文：「这是后人什么时候改的」「改自哪本书」「各本怎么分档」「未改的还留几处」「追改源头」「依《王制》/《文子》/晚出《尚書》改」「改了还得改注」「七型妄改」
- 英文：`when was this emended / source of the alteration / layer-position archiving / which edition started it / 追改层位 后人妄改七型 emendation archeology / variant survival`

**与相邻能力的区分**：本卡只做"追改源头定位＋按痕迹存活度分档归档"，不管定性（转 `zhiwu-leixing` CAP-03）、不管时间链繁殖序（转 `cuowu-fanzhi` CAP-13）、不管以他书今制律古的禁令本身（转 `yijin-lügu`）。若改动已牵连同书他篇旧文，归 `yinwen-zhenwei` 异文真伪；若注文可反推原貌，归 `jiuzhu-pipan` 旧注批判。本卡输出"这是X型妄改＋五档存活分布＋改风起于某书某时"，再交棒下游。

## E 执行步骤

**步骤 1 — 七型妄改对号（定性动机/依据）**
- 动作：对可疑改字，逐一对号七型——①不识古字而改；②以意改；③依晚出书改（如晚出《古文尚書》、《文子》、《考工記》、《王制》）；④依他篇/他传改；⑤为弥缝句读而改；⑥注家不通而改正文或注文；⑦以常见字改罕见字。可叠型（如"依晚出书改"＋"不识古字"同见）。
- 完成标准：写出"改者依据文本＋心理动因"二要素，如"依《王制》'被髮文身'常语、不识'劗'字"，而非空说"后人妄改"。

**步骤 2 — 层位三栏/五档归档（按痕迹存活度组织证据）**
- 动作：扫群书、同书他篇、类书古注、注文，分五档列账——已改者／已改而旧迹尚存者／未改者／引而已改者／引而未改者。
- 完成标准：每档至少列一书证，且"未改者"一栏非空（若全改则标"群书尽改"，改字流行度极高）。

**步骤 3 — 据"未改处"数量与分布反推改字流行时间与轨迹**
- 动作：未改处越多、时代越早（如唐初《羣書治要》仍存旧字）、分布越广，越证旧字是原貌；改风盛行之起点溯至"最早出现该字的那部权威书"（如晚出《尚書·武成》）。
- 完成标准：给出改字流行时间区间与源头文本，例如"起于晚出《尚書》盛行后，唐初尚有未改本"。

**步骤 4 — 两问必答（判停/降疑点）**
- 动作：每个定案必须同时答：①原文当作某；②今本何以成此（即步骤 1 的改字依据）。两问皆答方为完整定案。
- 完成标准：若只能答①答不出②（说不清"何以成此"），按规范降为**存疑**，不得径改；若两问皆备且有≥1路独立古本未改处佐证，方可定案出校记。

## B 边界

- **反场景**：文本本通、只是训诂不足，不该追"改自何处"，而应补古义（转 CAP-02 第三层）；纯假借异文可通者不必归一，不构"妄改"（转 `yijin-lügu`）。底本与类书一致者非追改。
- **失败模式**：
  - 只答"原文当作某"不答"今本何以成此"——改字仍有风险，落入 D-01 警告的"半案"。
  - 把"未改处"当成孤证而忽略群书尽改的强反证；或见注文与正文矛盾即削注从正（当倒推正文之误，转 `jiuzhu-pipan`）。
  - 七型对号空泛（只说"后人妄改"不指依据文本），等于没定位源头。
- **阶段 0 批判所得王氏盲点**：
  - **理校盖然性**：层位归档是空间分布的逆推，无实物初证时仍属假说；银雀山简校勘"十中有一失"，王氏亦偶误判追改源头。
  - **文例并非处处整齐**：以"未改处多"证原貌，前提是群书真各自承古；若群书同出一误源（如尽依已误俗本），"未改"反成假象。
  - **类书引文本身有讹**：引而未改者未必存古本之旧，据类书定档可能误判存活度。
  - 凡仅据"须改注才通"推追改源头而无异文/他书未改处佐证者，标待校。
