# 读不通排查序：先疑文本、次疑旧注、最后疑己

## R 原文

「高注云：『，履也，音「展」，非「展」也。』而各本乃誤爲「蹷」矣。」（《讀淮南子雜志書後》第16049行，王氏先信旧注、先疑传写"各本"之误）

「說經者期於得經意而已，前人傳注不皆合於經，則擇其合經者從之，其皆不合，則以己意逆經意，而參之他經，證以成訓，雖别爲之説，亦無不可。」（《讀書雜志》整理本序第1017行）

## I 自述

"读不通"是校勘最常见的起点，但**先怀疑谁**决定了你会不会冤枉原文。王氏给了一个反直觉的优先级：**先疑文本（传写致误），次疑旧注（注家曲说），最后才疑自己（未达古义）**。

常人的本能是"读不懂＝自己笨／古人深奥"，于是要么强解、要么以今意逆古。王氏恰恰反转：文本扞格，第一反应应是抄手传写讹、脱、衍、倒，或后人凭意妄改；其次才检查旧注是否望文生义、增字为解；只有当文本与旧注皆无可疑，才承认"是我未通古义"（如专名、古语词、古制）。

这条顺序是一道**防自误护栏**：把"疑己"放在最后，避免把文本错读成自己不懂；把"疑旧注"放在中间，破除"注疏必对"的迷信。它是 CAP-01 四闸门启动后、具体取证前的**第一道分流**。

## A1 书中案例

1. **问题**：《汉书》"天德无私亲，顺之和起，逆之害生"，"和"与"害"不相对。→**方法**：先疑文本——"顺逆""利害"本应对文，"和"显非其俦；查草书"和""利"形近，再查《文选》李注引文正作"利"。→**结论**："和"为"利"之草书误。→**结果**：改"和"为"利"，对文＋类书引文双证。（c12，先疑文本、不疑己）

2. **问题**：《汉书》"稍令楗为自保就"，颜师古训"就"为"成"，增字解作"保守且修成郡县"，文义扞格。→**方法**：次疑旧注——"就"非"成"义；以一声之转定"就"通"聚"，"保就"即"保聚"，引《左传》"不敢保聚"为证。→**结论**：颜注增字为解之失。→**结果**：训"就"为"聚"（读破），音转＋经传例证＋纠颜注。（c10，次疑旧注）

3. **问题**：《淮南·原道》"秉其要归之趣"与上下文不对且失韵。→**方法**：先疑文本——非自己未解，而是错简；对文、韵脚、《文子》异文三证指向"秉其要趣而归之"。→**结论**："归之趣"为错简。→**结果**：乙正。（c22，先疑文本）

## A2 未来触发

当用户面对以下情境时启用：
- 读一段古文/碑志/简牍某句扞格不通，纠结"是我没读懂，还是文本错了"。
- 旧注解释牵强，用户想确认"注家说得通吗"。
- 想"以意逆经"强解一句，但拿不准是否该先怀疑传抄。
- 校对时发现"按今义读不通"，不确定该改字还是补古义知识。

**语言信号（中英 key triggers）**：
- 中文：「读不懂」「这句不通」「是我理解错了吗」「旧注说不通」「是不是传抄错了」「以意逆经」「该疑文本还是疑注」
- 英文：`can't parse` / `doesn't cohere` / `is it me or the text` / `commentary doesn't fit` / `scribal error vs. my misreading` / `reverse-interpret the classic`

**与相邻能力的区分（初稿）**：本卡只解决"怀疑谁、按什么顺序排查"的分流，不做最终定谳。具体"传写致误"的字形机制归致误类型学（CAP-03），"旧注反证"的取证技术归旧注批判（CAP-07），"以声破假借"归以声求义（CF-01）。若已确认是"自己未达古义"（如专名、古制），本卡应转交训诂/音韵能力，而非继续疑文本。

## E 执行步骤

**步骤 1 — 红色信号识别**
- 动作：确认待校句确有"文不成义／句法参差／与上下文不属"等扞格。
- 完成标准：能说出哪一句、以什么方式"不成义"。无扞格则不启动排查。

**步骤 2 — 第一层：疑文本（传写致误）**
- 动作：查对文、句法、古音韵、隶/草/俗字形近、脱/衍/倒、旁记阑入等传写机制。
- 完成标准：能列出**至少一种传写致误机制**能解释该扞格（如"和""利"草书形近）。若能归属，则**不再上溯疑己**。

**步骤 3 — 第二层：疑旧注（注家曲说）**
- 动作：若文本无讹，检查旧注是否望文生义、增字为解、或随误文改注。
- 完成标准：能指出注文某处曲说（如颜注训"就"为"成"实增字）。若注误可解，则定谳于此。

**步骤 4 — 第三层：疑己（未达古义）**
- 动作：仅当前两层皆排除，承认自己未通古义——查专名、古语词、古制、古音假借。
- 完成标准：能说明"我未达的是哪一类古义"，并转向相应训诂/音韵能力。
- **判停点**：第一、二层任一层能定位，即停止，不再疑己；三层皆不能解，则**存疑不强解**，交 CAP-01 证据网收口或标注待核。

## B 边界

- **反场景**：文本本通、只是用户训诂知识不足——此时正确动作是"补古义知识"而非疑文本，滥用本卡会制造新讹。
- **书中警告的失败模式**：
  - 一上来"以意逆经"强解，把文本错读成自己不懂（x07：不识"适"通"啻"而改"有道"为"无道"）。
  - 为凑通同时改字并删字，连环动手（x02：改"入则御旁"为"入在御旁"又删上句"则"）。
  - 注家望文生义为误文打补丁——"上雍"脱"幸"，颜师古遂以"雍地形高"立说（x06）。
  - 遇"眼生"专名、数量词即改成形近常用字（x01：改"六云蜺"为"入云蜺"）。
- **阶段 0 批判所得的王氏盲点**：
  - **理校盖然性**：疑文本的结论仍是推测，非绝对。
  - **类书引文本身有讹**：群书所引未必存古本之旧。
  - **文例并非处处整齐**：对文强但不绝对，机械套用会误判。
  - **银雀山简十中有一失**：理校并非百发百中，存疑比妄断稳。
