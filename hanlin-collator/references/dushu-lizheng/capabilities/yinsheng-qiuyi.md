# 以声求义破假借（含古音部类审定）

## R 原文

> 懷祖嘗訓伯申云：「詁訓之指，存乎聲音。字之聲同聲近者，經傳往往假借。學者以聲求義，破其假借之字而讀以本字，則渙然冰釋；如其假借之字而强爲之解，則詰鞫爲病矣。」（约第1017行）

> 「《廣韻》『支』在五『支』，『芝』在七『之』，今音雖若近似，而古音絶不相通，故從支、從之之字古無通用者。」（约第16301行，開母廟石闕銘）

## I 自述

古书里"看不懂"的字，十有七八不是传抄错字，而是借字——古人写通假，读的是声音不是字形。王氏的核心主张是：训诂的钥匙在声音不在字形。一旦某字按字面讲不通，先别急着改字形，而要问"这个音古时候能通到哪个本字"。

这一步分两层。**第一层（CF-01 以声求义）**：声同声近之字往往假借，循着古音去找本字，文意就"涣然冰释"。**第二层（CF-02 古音部类审定）**：这是安全阀。今天读音相近（如支、芝今都读 zhī）绝不等于古人能通假；通不通要看上古韵部、声纽，不能凭耳朵。

关键姿态：破假借是"读破"——把借字按本字的意思去读，而非径改字形。改字是最后手段，读破是常规操作。

## A1 书中案例

- **晏子「怨利生孽」（约第9380行）**：孙渊如训"怨"为怨恶，致"怨利"二字不辞。王念孙据《左传》本字作"藴利"，定《晏子》"怨"为借字，与"藴""委"一声之转（皆训畜积），并引《荀子·哀公》"无怨财"杨倞注"怨读为藴"为证。结论：不轻改字，读"怨"为"藴"。
- **汉书「保就」（约第6022行）**：颜师古训"就"为"成"，增字解作"保守且修成郡县"，文义扞格。王以"聚""就"一声之转，定"保就"即"保聚"，引《逸周书·谥法》"就，会也"为证，明斥颜注"增字为解，而非其本旨"。
- **史记「范雎繆爲」（约第2351行）**：旧多不得其解。王云"爲"犹"謂"，"謂""爲"一声之转，故"繆爲"即"謬謂"（謬妄地告诉）。复以《秦策》"苏代僞爲齐王曰"同例互证。

## A2 未来触发

- 校读/翻译古书遇某字按字面"不辞""文不成义"，怀疑是假借或误字。
- 拿不准某字该"读破"还是"径改"时。
- 他人（含AI/注家）给出"增字才通"或"按形似改正"的解释，需要判定真伪。
- 处理 OCR/转录异文，需判断哪一个是借字、哪一个是讹字。
- 语言信号（中英 trigger）：「假借 / 通假 / 读为 / 一声之转 / 不辞 / 文不成义 / 借字」「jiacie / tongjia / read as / sound-loan / ungrammatical / doesn't parse」。
- 与相邻能力区分（初稿）：与 CAP-15「增字为解乱真」互补——本卡解决"借字读破"，CAP-15 解决"注家靠增字圆误"；与 CF-03「文例互证」不同，本卡从音入手、文例只作验证；与 CF-18「隶草形讹」不同，本卡处理声音通假而非字形讹混。

## E 执行步骤

1. **系联古音**：把可疑字按上古韵部、声纽归类（支/之、鱼/侯等），列出同音同部字族。完成标准：能说出该字属何部何纽，并列出可通假的候选字。
2. **确认声通**：用"声同 / 声近 / 一声之转"判定候选是否真能通假。**判停点**：若今音近而上古不同部（如支≠之、福古读逼不读肉），则否决通假，转查形讹（见 CF-18）。完成标准：找到经传中该通假实例或本字出处。
3. **寻本字**：从候选中确定本字，使文义通顺（如"怨"→"藴"）。完成标准：本字代入后原句成义，且不与上下文扦格。
4. **文例验证**：用本书他篇、他书同式用例、旧注反证交叉坐实（如《荀子》"无怨财"）。完成标准：至少一条独立文献/文例支持，或旧注残义印证。
5. **改读不轻改字**：结论写成"X读为Y"（读破），仅在确认是字误（非假借）时才改字。完成标准：结论明确区分"读破"与"改字"，并附古音依据。
6. **取音证（谐声·反切·直音）**：韵部声纽之外，再取三路硬音证——①谐声偏旁：从某声之字古同部（劗从赞声读攒、錣从叕声读焫、北声之背邶倍负同部）；②古人反切与直音：邹诞生"格一音阁"、杨倞"音古责反"证炮格本作格而非烙；③异文音证：一字在今古文/方言/别本中的异写本身即音通之证。完成标准：至少取到一路独立音证，或说明"无音证可取，转形讹"。
7. **人名地名异写先判通后判误**：专名异写遵循"声近者多通、形近而声远者多误"——翟景即翟强（景古读若疆）、公仲朋=冯=倗（声近通写，非误字）；申屠/申徒（胜屠即申徒）属假借；而"陶/陰"形近声远则订为形讹。完成标准：明确该异写归入"通写（不改）"还是"形讹（可订）"。

## B 边界

- **反场景**：所遇之字按字面本已通顺（如"保就"若强解为"保守"尚可读），勿强行破字；纯现代文本、后世白话不涉及通假者不用。
- **失败模式（阶段0批判 + 反例）**：
  - **破字过度即"破字失宜"**：裴学海评高邮王氏七大不足之一即"施训不恰，破字失宜"。凡无古音依据、仅凭意义相近便破读，即妄破（反例 x07：不识"適"通"啻"，改"有道"为"无道"；x09：不识"而"通"能"，乙倒"不而安"为"而不安"）。
  - **古音系统局限**：王氏音韵学依《广韵》及古韵分部，无出土文献全面印证；银雀山汉简出后，与《杂志》相重者八条，怀祖校是非者五、非者二、伯申非者一，说明古音推断亦可能失误。
  - **声近未必通假**：今音近≠古通（支/之例）；须以韵部、声纽双证，不可仅凭"声音相近"四字妄断。
  - 相邻易混淆：CF-18 隶草形讹（字形链）与本卡（声音链）常同现，须先判"音借"还是"形讹"再下手。
