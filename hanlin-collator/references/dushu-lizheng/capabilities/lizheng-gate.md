# 理证总程序：改字四道闸门与证据不全不动手

## R 原文

《史記雜志敘》云：「余曏好此學，研究《集解》《索隱》《正義》三家訓釋，而參攷經史諸子及群書所引，以釐正譌脱。」（约第994行）

「學者讀古人書，而不能正其傳寫之誤，又取不誤之文而妄改之，豈非古書之大不幸乎！」（《讀淮南子雜志書後》第16111行）

## I 自述

王氏校勘不是看到"读不通"就动手改字，而是一套有固定出口的**程序**。入口是一道红色信号闸：只有出现"文不成义／句法参差／失韵（依古音）／异文矛盾"中至少一种，才进入理证流程；文本原本通顺，就不改。

进入之后，先让待校之句依次过**四道闸门**：①是否与上下文相对、平列、排比成文？②是否破坏四字句或协畅句法？③是否失韵（依古音而非今音）？④是否有群书异文与旧注反证相参？四道闸门全通，才能下"改字"的结论。

最后用**五重证据网**收口：众本异文＋群书所引＋本书文例＋韵脚古音＋旧注批判，至少三路交汇方可定谳；任何一环缺失、证据互相冲突，就**存疑不动手**。这是整个理证链的"总开关"卡——它不自己判定具体讹误，而是决定该不该启动、以及何时交棒给以声求义、文例互证、失韵校验、旧注批判等下游能力。

## A1 书中案例

1. **问题**：《淮南·原道》"秉其要归之趣"与上句"因其自然而推之"不对，且"归""推"失韵。→**方法**：过闸门——对文失偶（闸门①）、句法参差（②）、失韵（③），再查《文子·道原》异文（④）。→**结论**：原作"秉其要趣而归之"，"归之趣"乃"归之"+注"趣"阑入正文之错简。→**结果**：乙正，对文＋韵脚＋异本三重互证，定谳。（case c22）

2. **问题**：《汉书·陆贾传》"马上得之，宁可以马上治乎"，"治"下孤出不妥。→**方法**：闸门①对文（"得之"对"治之"），闸门④《太平御览》两处及《史记》《汉纪》《通鉴》皆作"治之"。→**结论**：脱"之"字。→**结果**：补"之"，对文＋类书＋诸史三重证据。（c11）

3. **问题**：《荀子·劝学》"而致千里……而绝江河"，"江""河"与"里"失韵。→**方法**：闸门③失韵，查《文选》注、《大戴记》《说苑》引文皆作"江海"，"海"与"里"古韵相协。→**结论**：本作"江海"，"河"为后人改。→**结果**：校"江河"为"江海"。（c20）

## A2 未来触发

当用户面对以下情境时启用：
- 拿到一段读不通的古文、出土文献、墓志铭、仿古文或 OCR 转写文本，需要判断"该不该改、怎么改"。
- 遇到数据库 / 整理本多个异文版本，需要裁决"信哪个校本"。
- AI 生成的仿古文某句扞格，需区分"AI 臆造"还是"传抄讹误"。
- 用户直接问"这一句是不是错了 / 该怎么校"。
- 用户已动手改了字但拿不准依据是否充分。

**语言信号（中英 key triggers）**：
- 中文：「读不通」「这句不对」「是不是脱字/衍文」「哪个本子对」「怎么校」「疑似讹误」「该不该改」
- 英文：`doesn't make sense` / `textual error` / `which recension is right` / `emend / collate / variant reading` / `is this a scribal error`

**与相邻能力的区分（初稿）**：本卡是入口与"完成标准"卡，本身只做"启动判定＋四闸门＋证据网收口"。具体的"相对为文/平列"归文例互证（CF-03）、"失韵"归失韵校验（CF-04）、"以声破假借"归以声求义（CF-01）、"旧注反证"归旧注批判（CAP-07）。当红色信号只落在单一维度（如单纯韵脚问题），本卡应直接交棒，不重复下游步骤。

## E 执行步骤

**步骤 1 — 启动判定（是否进入理证）**
- 动作：扫描待校句，对照四类红色信号——文不成义、句法参差、失韵（古音）、异文矛盾。
- 完成标准：能明确指出**哪个字/哪一句**触发了**哪一类**信号。若文本原本通顺、无任一信号，则**停止**，不进入改字流程。

**步骤 2 — 过四道闸门**
- 闸门①相对为文：该句是否与上下文对文/平列/排比？完成标准：能列出对文项或确认"无对文"。
- 闸门②句法协畅：是否破坏四字句或固有句法节奏？完成标准：能说明句法如何参差。
- 闸门③失韵校验：依**古音**部类判断入韵字是否协（绝非今音）。完成标准：能给出韵部依据或确认"非韵文不触发"。
- 闸门④异文+旧注：有无群书异文、类书引文、旧注反证相参？完成标准：至少定位一条异文或注文证据。
- 判停点：若闸门①~④任一显示"文本本通、扞格另有来由（如自己未达古义）"，则**停止改字**，转入排查序（CAP-02）。

**步骤 3 — 五重证据网收口**
- 动作：将众本异文、群书所引、本书文例、韵脚古音、旧注批判五路逐条填入。
- 完成标准：至少**三路独立证据交汇**指向同一结论，方可定谳下改字；若五路中任两路相互冲突，或证据不足三路，则**判停存疑**，标注"待核"，不强行定论。
- **两问必答**：定案须同时答出①原文当作某、②今本何以成此（致误机制）。只答①者属半案，改字仍有风险，降为存疑（追改源头与五档归档见 `wangai-cengwei`）。
- **最小改动**：能靠句读/破读解决的，不判字误；能指出误因的，不径改字；批注优先于径改。可通之异文（假借、异体、同义）**存异即可，不必归一**。

**步骤 4 — 交棒**：结论既定则交 `dingan-wenshu` 出校记（标→证→断→因，并标铁案/稳案/疑案/阙疑）；涉及他书引文可靠性先经 `yinwen-zhenwei` 分级。

## B 边界

- **反场景**：纯字词释义讨论、作者本意/思想诠释、不涉及文本正误的文学赏析——这些不走理证流程，改字闸门不触发。
- **书中警告的失败模式**：
  - 证据孤证即动手＝妄改（单凭一处 OCR 截图或"字书无此字"就改，见 x20 鲍彪改"鰋鲤"为"鳝"）。
  - 为求通顺而增字为解，所增之字恰是"原文有误"的反向证据（CP-27）。
  - 改字以合韵却给不出古音依据，臆断的"合韵"常是错韵（x16、x17）。
- **阶段 0 批判所得的王氏盲点**：
  - **理校盖然性**：以理校推定原字仍是推测，非定谳；王氏自己亦有失（见下"银雀山"）。
  - **类书引文本身有讹**：群书所引并非皆存古本之旧，类书亦可能据已误俗本回改。
  - **文例并非处处整齐**：对文/平列是强证据但非绝对，后人偶有不整齐处，不可机械套用。
  - **破字过度失宜**：以通假破字若过滥，会"以通假为形讹，自乱其例"（裴学海七大不足之一）。
  - **银雀山简十中有一失**：银雀山竹简《晏子春秋》与《杂志》相重者八条，怀祖是者五、非者二，伯申非者一——理校并非百发百中，存疑比妄断更稳妥。
