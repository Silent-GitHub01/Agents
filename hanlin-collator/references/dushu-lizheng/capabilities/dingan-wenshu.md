# 定案文书范式与定案强度分级

## R 原文

《墨子雜志敘》云：「其脱誤不可知者，則槩從闕疑以俟來哲。」（约第9483行）

又《讀淮南子雜志書後》：「『舌』當爲『后』……『取』字文義不明，『取』當爲『敢』，字之誤也」；「津非行火之地，『津』疑當爲『澤』，草書相似而誤也」。（「當爲」例约第2804行、「疑當爲」例散见诸条）

## I 自述

上游的「改字四道闸门」与「五重证据网」只回答"该不该改、改作什么"，但**不教结论怎么落笔**。本卡管输出端：拿到定案后，校记、按语、札记、整理说明怎么写，结论标哪个强度，正文与校记如何分置。

王氏每一条定案都有固定文面——先"念孙案/引之曰"署名，再摘原文、列书证、下断语。它不是散文，而是一套可套用的四段范式：**标**（原文＋异文＋误处）→ **证**（证据链，先内证后外证、先文例后声形，大案分栏排比）→ **断**（定案语式）→ **因**（致误机制与改字轨迹，可省）。

关键在"强度分级"：同一条结论，凭"某当为某"与"某疑当为某"出口强度完全不同——"当为"是已断，"疑当为"是待决。把定案强度钉死在「铁案／稳案／疑案／阙疑」四级，再据级决定"正文径改出校记／正文从是存异／正文存旧按语存疑／不立说只录异文"，才是一条完整、可复核、可问责的校勘结论。

## A1 书中案例

1. **问题**：《史记·周本纪》"命南宫括散鹿台之财，发钜桥之粟"——"财"字是否后人追改？→**方法**：用四段范式落笔。**标**：今本"财"，《武成》正义引《周本纪》作"钱"。**证**：分十栏排比改字存活度——（一）《武成》正义明言《史记》作"钱"；（二）《群书治要》唐初本作"钱"；（三）《齐世家》《留侯世家》作"钱"；（四）《汉书》《汉纪》被改作"财"；（五）《逸周书》作"钱"；（六）《管子·版法解》作"钱"；（七）《淮南·主术》《道应》作"钱"；（八）纣作鹿台本以聚钱；（九）《吕览》"赋鹿台之钱"；（十）《说苑》"散鹿台之金钱"——并据"已改者／已改而旧迹尚存者／未改者／引而已改者／引而未改者"五档还原追改轨迹。**断**："散鹿台之财"本作"散鹿台之钱"，"财"乃后人依晚出《古文尚书》追改。**因**：晚出《尚书·武成》"散鹿台之财"盛行，学者习闻而遍改群书。→**结果**：证据链十路交汇且致误机制明了，定**铁案**，正文径改"财"为"钱"、出校记。

2. **问题**：《战国策·秦策》"褘布与"句，"求之"二字何字之讹？→**方法**：标原文"求之"，证《荀子》《韩诗外传》并作"莫之媒"、"之"与"知"声相混而误；然"求"所从讹之本字，诸书无确证。**断**：「『求之』二字未詳何字之譌，『又』即『父』之譌也」——以"未详"收束，不强行定"求"之本字（约第1591行）。→**结果**：本案与同条"是之喜""甚喜"等已定"当为"者形成对照——已断者出"当为"，无证者明言"未详"，定**阙疑**，正文存旧、按语录异。

3. **问题**：《管子》"『客』字之义未详"（约第1086行），脱文甚多致混战、斗为一事。→**方法**：标"客"字，证脱文致混、后以意删改；然"客"之本训无书可征。**断**：直言「『客』字之義未詳」，不立新说。→**结果**：定**阙疑**，只录异文与致误推测（脱文→后人删改），不径改。

## A2 未来触发

当用户进入"结论怎么写"环节时启用：
- 上游（lizheng-gate 等）已判"该改／该补／该删"，用户要落一条校记、按语、札记或整理说明。
- 用户给了一段定案文字，要求补全"证据链＋断语"的标准格式，或要求把口语结论改写成学术校记。
- 用户问"这条结论该标径改还是出校／存疑还是阙疑"，需要强度定级。
- 多本异文并存，需决定"正文取哪个、校记存哪些"。
- 用户要写"整理说明／凡例"，说明全书校改体例与阙疑原则。

**语言信号（中英 key triggers）**：
- 中文：「怎么写校记」「按语怎么下」「这条算铁案还是存疑」「出校还是径改」「断语怎么写」「标什么强度」「整理说明」
- 英文：`how to write the collation note` / `is this a settled emendation or doubtful` / `conjecture vs. certain` / `apparatus entry` / `should I mark it as doubtful` / `variant reading handling`

**与相邻能力的分工**：lizheng-gate 及其下游（文例互证、以声求义、失韵校验、旧注批判）负责"判改不改、定作什么"，是**决策端**；本卡是**输出端的下游**，只接收已决结论，负责"怎么表述、标哪级强度、正文与校记如何分置"。凡还在犹豫"该不该改"，交还 lizheng-gate，本卡不重复判据、不替上游定案。

## E 执行步骤

**步骤 1 — 定强度（四级）**
- 动作：按证据齐备度归级——铁案（声证＋形证＋文例＋多书外证齐备，且能解致误机制）／稳案（三证有二、致误机制明）／疑案（仅一证或机制不明）／阙疑（无证可断、异文各通）。
- 完成标准：结论句能明确冠以"铁／稳／疑／阙"之一，且级别与证据数对应，不出现"证据十路却标疑案"之类错配。

**步骤 2 — 按四段落笔**
- 标：摘原文＋异文＋误处（"今本某作某"）。完成标准：读者不看上下文即知"哪句、哪字、今本作何"。
- 证：列证据链，**先内证后外证、先文例后声形**；大案分栏排比（如散鹿台之钱十证按"改字存活度"分档）。完成标准：每条证据独立可读，能答"原文当作某"与"今本何以成此"两问。
- 断：用定案语式收束（见下清单）。完成标准：断语语式与强度一致——铁／稳案用"当为／乃某之譌／脱／衍／非也"，疑案用"疑当为"，阙疑用"未详"。
- 因（可选）：释致误机制与改字轨迹（"盖隶书X形似Y""盖后人依某书改"）。完成标准：能一句话讲清"何以成今本"。

**步骤 3 — 安全边界五查（落笔前逐项过）**
1. 不轻改经：经文有经学系统（今古文、师说）支持者，纵文义可疑不改。
2. 不改可通之异文：假借、异体、同义异文存异即可，不必归一（与／予、为／谓、唯／虽）。
3. 俗本不可从：以俗本改古本，虽俗本为某代权威亦不从。
4. 改字必具三证：文例/文义证＋声音/字形证＋他书/类书证；仅具一证入存疑。
5. 最小改动：能断句读解决的不断字误；能指出误因的不径改字；批注优先于改字。
- 完成标准：五项无一触发"越界"；凡触发任一项，降级处置（径改→出校→存疑→录异）。

**步骤 4 — 据级处置（四选一）**
- 铁案：正文径改＋出校记。
- 稳案：正文从是＋校记注明异文。
- 疑案：正文存旧＋按语存疑。
- 阙疑：不立说、只录异文（如"某字之义未详"）。
- 完成标准：正文所取字与校记/按语所记，与本卡所定强度一一对应，无"正文已改却无校记"或"已断却标未详"的矛盾。

**断语语式清单（强度由强到弱）**：
- 「某当为某」——已断正字（最强，铁/稳案）。
- 「某乃某之譌」——判形讹（强，须形证）。
- 「某下脱某字」／「某上脱某字」——判脱文。
- 「某衍文」——判衍文。
- 「某本作某，今本作某非也」——驳旧注/俗本而正。
- 「疑当为某」——有倾向未敢定（疑案，弱一档）。
- 「未详」／「疑」——无证可断，存疑待后（阙疑）。
- **强度差别**：「当为」=已断，须三证齐方向一致；「疑当为」=方向可疑而据不足，仅一证或机制不明时用，正文不得径改，只能按语存疑；「未详」=连可疑方向都无书可征，只录异文不立说。三者不可混用——把"疑当为"写成"当为"即妄改。

## B 边界

- **反场景**：用户只要一句口语结论（"这句是错的"）、不要正式校记时，不要硬套四段模板——直接给判定与一句理由即可；模板只在"要落笔成文"时启用。
- **书中警告的失败模式**：
  - 把"疑当为"写成"当为"——强度越级即妄断（银雀山简十中有一失，理校非百发百中）。
  - 断语强而下证弱——"当为"却只具孤证，违反"改字必具三证"。
  - 凡不可通者皆以为错简／强说致误之由——王氏批评此轻率，无据则应从阙疑。
  - 最小改动失守——能批注指出误因却径改字，破坏古本可溯性。
- **阶段 0 批判（王氏盲点）**：
  - 理校盖然性：以理校推定原字仍是推测，非定谳；"当为"之语亦可能失（见银雀山十中有一）。
  - 类书引文本身有讹：外证未必存古本之旧，据类书定"铁案"须先证类书所据非已误俗本。
  - 文例非处处整齐：对文/平列是强证据但非绝对，机械套用会造伪铁案。
  - 故：凡涉经文、罕见字、通假字，宁降一级（稳→疑、铁→稳），以"出校/存疑"代"径改"，比妄断更稳。
