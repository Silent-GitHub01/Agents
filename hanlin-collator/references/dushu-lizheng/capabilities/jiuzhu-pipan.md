# 旧注批判与注正双误反推

## R 原文

「高注囊括六蓺，旁通百家，訓詁既詳，音讀尤審……然瑜不揜瑕，亦時有千慮之一失。」（《讀淮南子雜志書後》第16113行）

「正文『蘋』字誤作『萍』，後人遂改注文之『蘋大萍』爲『萍大蘋』，以從已誤之正文矣。」（《讀淮南子雜志書後》第16084行）

「後人不知，而改『厲爽』爲『爽傷』，又改注文之『厲爽』爲『爽病』，甚矣其謬也。」（同上第16102行）

## I 自述

旧注不是校勘的终点，而是两种相反的证据源。王氏用旧注有**正反两手**：

**正面（旧注作负面证据／时间胶囊）**：注文是作者时代的"时间胶囊"——若注释恰释某字而正文无此字，说明正文脱字；若注与正文扦格，说明要么正文误、要么注误，由此反推原貌。典型如"若正文作廣成傳舍，则《索隐》为赘语矣"——注文多馀即反证正文之误。

**反面（注正双误反推）**：后人既改正文、又改注文以自圆其说，这是妄改的**铁证红旗**。更妙的是，被改的注文里往往残留未被尽改的"原字释义"，正好反推正文原字。如正文"蘋"误"萍"，后人连带把高注"蘋大萍"改"萍大蘋"以从误——注中残存的"蘋"字即锁定正文原作"蘋"。

同时，旧注本身不可盲从：高诱"千虑一失"，须用**上下文／韵／文例**三把尺检验。本卡是"批判性使用旧注"的取证技术，常接在 CAP-01 闸门④、CAP-02 第二层之后。

## A1 书中案例

1. **问题**：《汉书》"稍令楗为自保就"，颜师古训"就"为"成"，增字解作"保守且修成郡县"，文义扞格。→**方法**：旧注批判——"保就"上下同义当为连语；以一声之转定"就"通"聚"，引《逸周书》"就，会也"、《左传》"不敢保聚"。→**结论**：颜注"增字为解，而非其本旨"。→**结果**：训"就"为"聚"（读破）。（c10，旧注批判）

2. **问题**：《淮南·原道》"夫蘋树根于水"，高注"蘋，大萍也"，而正文作"萍"。→**方法**：注正双误反推——正文"蘋"误"萍"后，后人改注"蘋大萍"为"萍大蘋"以从误；注中残存"蘋"字即反证正文原作"蘋"。→**结论**：正文原是"蘋"，"萍"为传写误、注随误改。→**结果**：正文当从"蘋"。反推正字。（第16084行）

3. **问题**：《淮南》"五味乱口，使口厉爽"，高注训"厉"为病、"爽"为伤；后人改"厉爽"为"爽伤"，又改注"厉爽"为"爽病"。→**方法**：注正双误反推——既改正文又改注以弥缝，是妄改铁证；且"爽"古读若"霜"与"明、聪、扬"为韵，改后失韵，三重印证。→**结论**：原"厉爽"不误，妄改失韵又改注从误。→**结果**：存原字"厉爽"。（第16102行）

## A2 未来触发

当用户面对以下情境时启用：
- 某"权威译注/整理本"为通顺新增、删改一字，声称据古注——需判断能否采信。
- 正文与旧注互相矛盾，不知该信哪边、如何反推原貌。
- 见到"改正文又改注以自圆"的情况，要识别这是妄改红旗。
- 想用旧注作为校勘证据（支持或反证某字）。

**语言信号（中英 key triggers）**：
- 中文：「旧注说不通」「注和正文矛盾」「是不是据注妄增」「改注从误」「注当时间胶囊」「权威注本可靠吗」「注正双误」
- 英文：`commentary contradicts text` / `is the old gloss reliable` / `emendation to fit the commentary` / `gloss as negative evidence` / `time-capsule of original reading`

**与相邻能力的区分（初稿）**：本卡专管"如何用旧注取证与反推"，不重复上游的"是否该启动理证"（CAP-01）、"先疑文本还是疑注"（CAP-02 第二层）。它也与以声求义（CF-01）交叉——"保就"之破字借"聚"是用音转，但本卡强调的是"借旧注之失证字"，角度在注不在声。若仅判断"某字为通假"，交 CF-01；若用"注文残义反推正字"，留在本卡。

## E 执行步骤

**步骤 1 — 旧注作负面证据**
- 动作：比对注文与正文——(a) 注释某字而正文无此字 ⇒ 正文脱；(b) 注与正文扦格 ⇒ 正文误或注误，据文例/韵/异文定哪边。
- 完成标准：能指出注与正文的一处**矛盾或印证**并说明其校勘含义（如"若正文作X则注为赘语"）。

**步骤 2 — 注正双误反推**
- 动作：凡见"改正文又改注以自圆"，先视为**红旗**；在改后注文中搜寻未被尽改的"原字释义"（如"蘋大萍"残留"蘋"），据此反推正文原字。
- 完成标准：在注文中定位到**至少一个原字残留证据**，并据此还原正文。

**步骤 3 — 三把尺检验旧注**
- 动作：用**上下文／韵／文例**检验旧注是否"千虑一失"；不盲从权威。
- 完成标准：旧注经三尺检验无误则存信；若注误，须另寻异文/类书证据支撑，不以孤注定谳。
- **判停点**：若旧注既被证误、又无他证可代，则存疑（CAP-01 证据网收口），不强以注为据。

## B 边界

- **反场景**：纯注解疏义理、不涉及文本正误的注疏研读——此时旧注是学习对象，不是校勘证据。
- **书中警告的失败模式**：
  - 改注从误连环：既误正文又改注以牵合（x14：蘋→萍 改注"蘋大萍"为"萍大蘋"；x15：櫓→矰 改"不能独穿"为"不能独射"又改注"櫓，大盾"为"矰，犹矢"）。
  - 误字沿入字书韵书成"权威"讹（x12、x19：《玉篇》以下皆承误）。
  - 据彼改此：依他书异文改本书韵字而失韵（x18：依《文子》改"騶"为"御"）。
- **阶段 0 批判所得的王氏盲点**：
  - **高注千虑一失**：旧注本身可能误，以其为证据须另寻他证，不可独信。
  - **类书引文本身有讹**：所据群书引文未必存古本之旧，注反推的"原貌"可能仍是讹。
  - **理校盖然性**：注正双误反推的结论仍是推测。
  - **银雀山简十中有一失**：理校非百发百中，旧注反推存疑比妄断稳。
