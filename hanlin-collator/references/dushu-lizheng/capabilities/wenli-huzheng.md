# 文例互证（对文·平列·相对为文·字数齐一）

## R 原文

「古人之文不嫌於複，『土地之宜』與『水土之便』對文，删去一字，則句法參差矣。」（约第1162行，逸周書·大聚篇）

「『百草』與『百藥』對文。今本『百草』與『五味』互易，則義不可通。」（约第1166行，逸周書·弟二）

## I 自述

古书行文讲究对称：上下句常"对文"（相对为文）、"平列"（并列同构），或四字为句、字数齐一。当某一句读不通、某字可疑时，先看它相邻的平行句结构是否齐整。

若本该对举处不对称（如"百×"对"百×"却错成"百×"对"五×"），或四字句字数不齐，则错处大概率在破坏对称的那一字——而非整句文意有问题。句法结构本身即可作校勘证据，常与音韵、异文无关。

关键动作：以邻句的同构反推本句的正字或脱衍。结构齐整是古书常态，"不对文/字数参差"就是故障信号。

## A1 书中案例

1. **逸周書「具百藥…畜百草」对文互乙**（约第1166行）：今本"具百藥以備疾災，畜五味以備百草"，念孫据"百草"与"百藥"当对文，定"百草""五味"互易，乙正为"畜百草以備五味"，使"百草—百藥""五味—疾災"俱儷。→ 对文结构直接锁定乙倒。

2. **史記「彀騎萬三千」脱"匹"字**（约第2547行）："選車千三百乘，彀騎萬三千"缺量词。念孫据《蘇秦傳》"車千乘，騎萬匹"以"乘""匹"对文，断此处当有"匹"字，复以《御覽》《漢書》皆作"萬三千匹"坐实。→ 字数齐一 + 异文双证脱文。

3. **漢書「順之和起」之"和"當爲"利"**（约第5401行）："順之和起，逆之害生"中"和"与"害"不相儷。念孫据"順逆""利害"对文，定"和"當作"利"（草書形近而誤），《文選》李注引正作"利"。→ 对文失儷入手，归为字形讹。

## A2 未来触发

**场景**：校勘/整理古书、OCR或转录文本、读不通某句想改字时；用户贴出对仗/排比句说"这里不对/多一字/少一字"；拿到仿古骈文或韵文想定位故障字。

**语言信号（中英）**：
- 中文："这两句对不上""字数不齐""多/少了一个字""句式不工整""上下不相对"
- 英文："this couplet doesn't match / unparallel / missing a character / uneven line length / 对文 文例 平列"

**与相邻能力区分（初稿）**：本卡只看句法对称/字数，不动音韵；若故障表现为"该押韵处不协"则转 `shiyun-xiaoyan` 失韵校验；若涉及联绵词/同义复词被拆分则转 `lianyu-fenxun` 连语不可分训；若对文锁定后需破假借则转 `yinsheng-qiuyi` 以声求义。

## E 执行步骤

1. **标结构**：圈出可疑句及其相邻平行句，判明是否为对文/平列/四字句。完成标准：能列出"本应 X 对 X"的同构对照。
2. **找破口**：对比同构，定位破坏对称的那一字（错、脱、衍、倒）。完成标准：指出具体哪一字破坏齐整，并给出"正字/脱文/衍文/乙倒"之一。
3. **求参证**：用本书他篇同式文例 + 异本/类书引文复核。完成标准：至少一处独立文例或异文支持；证据不足则存疑，不单凭对称下手。
4. **补字须三证齐备**：据对文/句式判为脱文而要补字时，须同时满足**文义通 + 文例合 + 外证（他书/类书引文有此字或注文可证）**三者；仅合文义而无外证者，只可存疑，**不可径补**（参 `dingan-wenshu` 定案强度分级）。完成标准：三证列名；缺一则降为存疑。

## B 边界

- **反场景**：散句、确非对文处（古书也有不对仗句），不可因一处不"工整"就硬改；纯文意不通而结构本齐整者，本卡不适用，转 `lizheng-gate` 读不通排查序。
- **失败模式**：把"对文"当绝对律——王氏亦承认古书"不嫌於複"，偶有不齐；因想象的对仗去臆补字，反成妄加（见 `zengzi-weijie` 增字为解）。
- **阶段0批判所得边界**：常人遇不对文先疑自己"读不懂"，王氏反将"疑文本结构"置前；但须防过度对称癖——结构证据须与他证收敛，孤证不动手。
