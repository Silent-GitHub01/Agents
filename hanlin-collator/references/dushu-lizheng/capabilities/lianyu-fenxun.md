# 连语不可分训（古人自有複语 / 同义复词）

## R 原文

> 「凡連語之字，皆上下同義，不可分訓。説者望文生義，往往穿鑿，而失其本指。」（约第6244行，漢書「連語」专条）

> 「『陵夷』之爲『陵遲』，猶『逶夷』之爲『逶遲』……『陵夷』不可謂『如陵之夷』，猶『衰微』不可謂『如衰之微』也。」（约第6244行）

## I 自述

古人写文章有一种今人容易踩坑的习惯：把两个意思相近或声音相类的字叠在一起成一个词（同义复词、联绵词、双声叠韵词），整体表一个意思，单拆任何一半都讲不通。王氏铁律是"连语之字，上下同义，不可分训"。

难点在反直觉：现代人见"陵夷"会按字面拆成"丘陵"+"平"，见"犹豫"拆成"兽名"+"备豫"，还觉得自己讲得通。其实"陵"与"夷"都是"平"义，叠起来仍是"平"；"奔"与"踶"都是"疾行"，叠起来是"奔驰"。一旦分训，就会出现"如丘陵之渐平"这类牵强曲说。

判断口诀：两个字叠在一起、换任一个字意思不变、且各自单讲反而别扭——多半是连语，必须整体训。

## A1 书中案例

- **「流貤」（约第6244行）**：应劭训"貤"为"物之重次弟"，师古因之，分"流貤"为二义。王念孙云"貤"读与"施"同（移也），"流貤"取"旁及"义，即今人"移封""移卖"。若分训"重次弟"则"流貤"二字义不相属，且须移字加数语方通，显为穿凿。
- **「陵夷」（约第6244行）**：师古以"陵"为丘陵、"夷"为平，解为"颓赞若丘陵之渐平"。王引《史记·高祖功臣表》"陵夷衰微"四字平列，证"陵""夷"皆平义；又引"陵迟犹陂沱、逶迟犹逶蛇"相对为文，明斥"如陵之夷"之误。
- **「奔踶」（约第6244行）**：师古分"奔"（乘之即奔）与"踶"（立则蹋人）为二。王云"踶亦奔也"，"奔踶"犹"奔驰"；若训"踶"为蹋，则与下文"泛驾之马亦在御之"全不涉。

## A2 未来触发

- 注释/翻译古书，遇"XX"二字叠用、按各自字面拆分后意思别扭或需加字才通。
- 现代整理本/AI 把"陵夷""犹豫""逶迟"等拆成两词并分别释义。
- 怀疑某处"重复冗余"想删其一字（如"陵、夷"）。
- 语言信号（中英 trigger）：「连语 / 複语 / 联绵词 / 同义复词 / 上下同义 / 不可分训 / 望文生义」「reduplicative binome / coordinate compound / don't split / tautological pair」。
- 与相邻能力区分（初稿）：与 CF-03「文例互证」不同——本卡管"词内两字是否可拆"，文例管"句间是否对称对文"（如"菽飯藿羹"是两句对举，可分别训，非连语）；与 CAP-04「以声求义」交集在双声叠韵词（如"逶迟"），但本卡重在"整体义不可分"，破读只是其下位手段。

## E 执行步骤

1. **识别连语**：看叠用二字是否同义、双声、或叠韵；试换成任一字义是否仍通。完成标准：列出该词在本书/他书的连文形式（如"陵迟""逶迟"）。
2. **整体义训释**：不拆字，依词族通义定整体训（"陵夷"=平、"奔踶"=奔驰）。完成标准：整体义代入原句通顺，无须增删字。
3. **他处文例验证**：查同书他篇、经传、旧注中该连语的整体用例。完成标准：至少一条独立用例支持整体义。
4. **判停点**：若上下二字义并不相近、或拆开后各自成词且文意更顺，则疑为形讹/借字（转 CAP-04 以声求义或 CF-18 形讹），不当判连语。

## B 边界

- **反场景**：真正的并列结构（"菽飯、藿羹""公義、私怒"）是两句对举，本就可分训，勿误判为连语；句法对称处宜用 CF-03 文例互证而非本卡。
- **失败模式**：注家"望文生义、往往穿凿"（R 段原警）。凡见叠用字便逐字求解，是王氏所斥主流错误；现代编辑"去冗余删其一字"亦属此类（如删"陵"留"夷"）。
- **阶段0批判**：连语判定依赖词义训诂积累，初学者易把"偶然同义连文"误当联绵词而强合；须以音（双声叠韵）与义（同义）双证，孤证不立。
- 相邻易混淆：CF-03 文例互证（句间对称）与本卡（词内整体）方向相反，触发时先定位"词内"还是"句间"。
