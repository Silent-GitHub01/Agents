# 虚词语义推勘（转语词·发语词·反训）

## R 原文

> 「亡讀如無，或言『亡』，或言『亡其』，皆轉語詞也。」（约第2348行，史記·范雎列傳）

> 「『來』與『往』義相反，而謂『往』爲『來』者，亦猶『亂』之爲『治』，『故』之爲『今』，『擾』之爲『安』也。」（约第2790行，史記·樂書「來古」條）

## I 自述

古汉语里大量"读不通"的疙瘩，出在虚词——发语词、转语词（抑/亡其/意亦）、反诘助词（也/邪）、以及成系统的"反训"词（乱=治、来=往、故=今）。现代人习惯拿今义当实义去抠，一抠就错。

王氏处理虚词有三把刷子：**其一，转语词**——"亡其""意亦""抑"都是"还是/抑或"类转折连词，不是实词；**其二，一声之转**——虚词因声音相通而通用（謂=爲、亡=無、能=乃、而=能）；**其三，反训**——古书里有一批词"义相反而名相涵"（乱训治、来训往），按字面反义去读反而讲不通。

关键姿态：先判"这个字是虚词还是实词"。若它在句间起连接、语气、发端作用，优先走音转与反训，而非改实词迁就。

## A1 书中案例

- **范雎「亡其」（约第2348行）**：《索隐》训"亡"为"轻蔑"，义不可通。王念孙定"亡读如無"，"亡其"为转语词（还是/抑或），并广引《庄子·外物》《吕氏春秋》《韩策》等"亡其""妄其""意亦"诸例，证凡言"亡其"者皆转语词。
- **范雎「繆爲」（约第2351行）**："爲"犹"謂"，"謂""爲"一声之转，故"繆爲"即"謬謂"（謬妄地告诉宦者）；复以《秦策》"苏代僞爲齐王曰"同例互证，虚词一读即通。
- **乐书「來古」（约第2790行）**：《索隐》倒释"來古"为"古来"，致"述古来"不辞。王云"來"即"往"（反训），"述來古"＝"述往古"，并引"亂之爲治、故之爲今、擾之爲安"明反训通例。

## A2 未来触发

- 古书某句因一个"副词/连词/语气词"讲不通，想改其实词（名词动词）来迁就。
- 遇"亡其""意亦""抑""岂不""也/邪"等虚词，需判定其语法功能与读音。
- 见"来=往""乱=治"类反义用法，需要确认是否为反训而非讹字。
- 语言信号（中英 trigger）：「虚词 / 发语词 / 转语词 / 反训 / 一声之转 / 读为 / 不辞 / 文不成义」「function word / connective / fanxun / antonym-as-synonym / read as」。
- 与相邻能力区分（初稿）：与 CAP-04「以声求义」共享"一声之转/读为"手段，但本卡专管虚词与反训（语法/语气层），CAP-04 管实词借字（词汇层）；与 CF-03「文例互证」不同，本卡从虚词语法功能入手。

## E 执行步骤

1. **定位词性**：判断可疑字在句中是虚词（发端、转折、语气、反诘）还是实词。完成标准：能说出它承担的语法功能（如"亡其"＝抑或连词）。
2. **查音转通假**：依"一声之转/读为"找同音虚词（亡=無、爲=謂、能=乃、而=能）。完成标准：找到经传或《释词》同式用例。
3. **查反训义**：若该字今义与语境相反，试反训（乱=治、来=往、故=今、扰=安）。完成标准：反训代入后语气/逻辑通顺。
4. **文例与旧注验证**：用本书他篇、他书同式、旧注残义交叉坐实。完成标准：至少一条独立用例支持。
5. **判停点**：若按今义实义讲已通、且全书无扞格，则不强行作虚词/反训解；若须改实词才能通顺，先回头走 CAP-04 确认是否假借。

## B 边界

- **反场景**：可疑字确为实词且按字面已通（如"保就"之争其实是实义复合），勿硬套虚词；纯现代白话、西文句法无关。
- **失败模式（反例）**：不识假借而妄动实词——x07 不识"適"通"啻"，改"有道"为"无道"以迁就；x08 不识"能"通"乃"，删"能"字；x09 不识"而"通"能"，乙倒"不而安"为"而不安"。三者皆因未先勘虚词而致误。
- **阶段0批判**：虚词语义推勘依赖《经传释词》式系统总结，王氏亦被裴学海评"以通假为形讹，自乱其例"——有时把本属字形讹混的字误判为通假；声近未必通（须古音部类双证，见 CAP-04 古音审定）。
- 相邻易混淆：与 CAP-04 同用"读为/一声之转"，触发时先分"虚词层"还是"实词层"。
