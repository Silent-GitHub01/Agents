# 失韵校验与合韵陷阱（失韵即可疑；改字以合韵而实非韵/反失韵是重灾区）

## R 原文

「若夫入韻之字，或有譌脱，或經妄改，則其韻遂亡，故有因字誤而失其韻者。」（约第16093行，讀淮南子雜志書後）

「有改字以合韻而實非韻者……有改字以合韻而反失其韻者。」（约第16100–16101行，書後論合韵陷阱十八例）

## I 自述

韵脚是古书（韵文与偶句，乃至散文中的协韵句）的天然校验器：凡该押韵处不协，必是讹脱或妄改留下的痕迹，所以"失韵即可疑"是入口信号。

但本卡更要命的是反向陷阱——"改字以合韵"常是妄改重灾区。后人打着"协韵"旗号动手，结果要么"合的是今韵而非古韵"（实非韵），要么"为凑一韵反而拆散原韵组"（反失韵）。判韵必须用古音韵部，绝非今音；且改后须既合古韵又不失本义，"只合今韵"一律否决。

一句话：失韵→排查；合韵→警惕。

## A1 书中案例

1. **荀子「絶江河」本作「絶江海」**（约第11632行）：劝学"而致千里…而絶江河"与"里"失韵。念孫据"海"与"里"古韵相协，定本作"江海"；复以《文選》李注、《大戴記》《説苑》三处引文皆作"江海"坐实，今本"河"乃后人改。→ 失韵 + 群书引文定妄改。

2. **逸周書「焚其草木」衍"木"字**（约第1401行）："澤有獸而焚其草"与下句"巧"为韵，加"木"则破"草—巧"韵。念孫以"上下文皆用韻"为旁证，定"木"为妄增。→ 失韵即定衍文。

3. **書後"改字以合韵而反失其韵"例**（约第16101行）："無鄉之社，易爲肉黍；無國之稷，易爲求福"，本"社—黍""稷—福"为韵（福古读偪）。后人不识古音，倒"肉黍"为"黍肉"去凑"福"，反破原有两对韵。→ 合韵陷阱典型：以今音揣古韵，十改九失。

## A2 未来触发

**场景**：校韵文/偶句、诗词转录本、仿古骈文；用户说"这句不押韵""帮他凑个韵""某字为了押韵改一下"；拿到据他书"协韵"回改的本子。

**语言信号（中英）**：
- 中文："不押韵""失韵""为了协韵改的字""凑韵""韵脚不对"
- 英文："doesn't rhyme / off-rhyme / emend for rhyme / 失韵 协韵 合韵"

**与相邻能力区分（初稿）**：本卡专管"韵"；若故障是句法不对称则转 `wenli-huzheng` 文例互证；若改字涉及通假破读则转 `yinsheng-qiuyi` 以声求义；若韵字被依他书异文改则转 `yijin-lügu` 不据彼改此（韵文场景）。

## E 执行步骤（韵脚校验操作流程）

1. **定韵域**：先判当前是否韵文/偶句/散文协韵句，标出疑似韵脚字与协韵位置。完成标准：列出"当协处"及候选韵脚。
2. **用古音核**：以古音韵部（非今读）核对协否——参考同篇/同书韵例与王氏已归纳部居（如"福"古读偪、"附"在候部非御部之"度"韵）。完成标准：判定"协/失韵"，失韵则标高危疑似区。
3. **验合韵真伪**：遇"后人改字以合韵"，查其合的是古韵还是今韵；确认改后是否既合古韵又不失本义。仅合今韵 / 拆散原韵组 / 改字又改注自圆者，一律否决。完成标准：给出"古韵依据成立 or 不成立"结论。
4. **收敛定谳**：以异文、类书、文例、旧注四路参证；五重证据不足则存疑，不动手。完成标准：改动须有≥2路独立证据，否则标记待校。

## B 边界

- **"以今音揣古韵"陷阱**：今音近似≠古通（如"附—度"实不同部），十改九失；凡给不出古音部依据的"协韵"改字，直接否决。
- **"古书偶有不整齐"边界**：并非所有不协都是讹——须看同书韵例与该篇用韵习惯，不可一见不韵就动刀；王氏亦用"上下文皆用韵"作旁证，说明单句失韵需上下文佐证。
- **失败模式**：为凑韵而增删字却令邻字"文不成义"（如"德將來附"使"若美"不词）；改字又改注文牵合（见 `jiuzhu-pipan` 旧注批判）。
- **阶段0批判所得边界**：常人把"读着顺/押韵"当正确信号；王氏反向——"合韵"恰是高危红旗，须先证古韵再采信。
