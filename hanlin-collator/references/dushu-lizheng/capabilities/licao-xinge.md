# 隶草字形讹混推因（重建讹变链：篆→隶→草→俗，形近致讹）

## R 原文

「有因隷書而誤者。《時則篇》『孟秋之月，其兵戉。』『戉』，古『鉞』字也，而各本乃誤爲『戈』矣。《齊俗篇》……『咊』與『味』字相似，而各本遂誤爲『味』矣。」（约第16052行，讀淮南子雜志書後）

「有因草書而誤者。《齊俗篇》『柱不可以摘齒，筳不可以持屋』……『筳』與『筐』草書相似，而各本遂誤爲『筐』矣。」（约第16053行，讀淮南子雜志書後）

## I 自述

本卡管"形近致讹"中专精的一支：讹变不是随机的，而是沿着字体演变链（篆→隶→草→俗）逐步走样，每一步都有可枚举的"形近对手集"。王氏能断"某误为某"，是因为他熟汉碑隶变、俗写讹体，知道"戉"隶或作"戈"形、"筳"草与"筐"近、"北/外""交/反"常混。

诊断流程：先锁定可疑字，再枚举它在各字体阶段所有"形近混用"的对手，结合文义与古音逐一排除，落到正字。可迁移到任何字体/字符混淆排查（碑帖OCR、手写识别、异体字形近）。关键纪律：不能只凭"楷体看着像"就定讹——须还原到该字实际经历的字体阶段去比对。

## A1 书中案例

1. **淮南·时则「戉→戈」等隶变**（第16052行）："戉"古"鉞"字，隶书"戉"或作近"戈"形，各本遂误为"戈"；又"咊"与"味"隶形相似而误"味"。念孙据古字+高注还原。→ 隶书形近对手集锁定正字。
2. **淮南·齐俗「筳→筐」草书**（第16053行）："筳"（小簪）与"筐"草书相似，各本误"筳"为"筐"，使"小簪摘齿"句义全非。念孙据草书形近+文义复原"筳"。→ 草書形讹须识草体。
3. **漢書·陸賈「順之和起→順之利起」**（cases c12，约第5401行）："顺之和起，逆之害生"，"和"与"害"不相儷；念孙据"顺逆""利害"对文定"和"当为"利"，二字草書之误，且《文選》李注引正作"利"。→ 对文失儷入手归草书形讹。

## A2 未来触发

**场景**：校碑帖/OCR把某字识成形近字（如"出"省形作"士"、"咄"误"吐"）；古书出现群书无征的生僻字疑为形讹；隶定、草写文本中某字与文义扞格；需要"重建某字讹变链"的字形推理。

**语言信号（中英）**：
- 中文："这俩字形太像了""碑帖OCR认错""草书/隶书形似""形近致讹""篆隶讹变"
- 英文："palaeographic confusion / scribal error / clerical-script similar / 隶草 形讹 讹变链"

**与相邻能力区分（初稿）**：本卡专管"字体演变形近讹"，维度是字形谱系；旁记/二本叠加转 `pangji-wuhe`；重文诱发转 `yujing-zhiwu`；因误致误链转 `cuowu-fanzhi`；音韵破假借转 `yinsheng-qiuyi` 以声求义（注意：通假非形讹，裴学海"以通假为形讹自乱其例"正戒此混）。

## E 执行步骤

1. **建对手集**：对可疑字，枚举它在篆/隶/草/俗各阶段所有"形近混用"对手（参考汉碑、俗写）。完成标准：列出≥2个候选正字及其形近依据。
2. **文义+音韵筛**：以本文文例、对文、韵脚、古音逐一排除，落到使文义通顺者。完成标准：候选字代入后文义/对文/韵皆通。
3. **异文坐实**：以善本、类书引文、他篇同式文例确认正字；无实物佐证则存疑。完成标准：正字有版本或类书硬证，或至少文义音韵全通。

**建对手集时优先查：俗书偏旁混讹对表**（王氏反复使用，可批量清扫同机制讹字）

| 混讹偏旁 | 实例 | 备注 |
|---|---|---|
| 力 / 刀 | 劲譌到、勮譌剧、劫譌刦 | 从力之字或譌从刀 |
| 巠 / 至 | 痙譌痓、輕譌輊 | 巠旁俗作而譌至 |
| 巫 / 圣 | 誣 / 輕 互譌 | 俗书巫旁与圣旁混 |
| 竹 / 艸 | 诸字互譌 | 字书俗体可证 |
| 木 / 扌、亻 / 彳 | 循 / 脩 亦半属此 | |
| 大 / 犬、肉 / 肙 | 肉俗作肙（《干禄字书》《广韵》） | 少见字被常见字替换 |

判定后**连带清扫**：同机制在一书内反复出现者（如"从力譌从刀"见于《战国策》与《韩世家》），可举同类字群互证，批量坐实。

## B 边界

- **反场景**：文义音韵皆通、且无异文冲突者，不是形讹，勿妄改；通假字（声同声近）不是形讹，转 `yinsheng-qiuyi`。
- **失败模式**：只凭楷体"看着像"定讹而不还原字体阶段；把真通假当形讹剔出（裴学海"七不足"之"以通假为形讹自乱其例"）；枚举对手集不全而漏正字。
- **阶段0批判·理校盖然性风险**：形讹推因纯靠字形知识储备，王氏偶亦以己意定形讹而失——银雀山汉简校勘有"十中有一失"之诫。裴学海"七不足"复揭"忽于审证"：未见善本实物、仅据"形近"臆断，可能以今楷度古隶而错判。凡无版本/类书印证者，标待校。
