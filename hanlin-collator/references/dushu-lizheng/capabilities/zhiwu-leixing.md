# 推致误之由：致误二分与六十二例类型学

## R 原文

「懷祖於《讀淮南子雜志書後》長文中概括古書錯亂之由爲傳寫譌脱者半與憑意妄改者半兩種，復將譌誤衍奪與增删移易參互之，區爲六十二種類型，並舉實例以證。」（《讀書雜志》整理本序第1007行）

「以上六十二條，先言誤字，繼言衍脱錯簡，繼言不明古書體例、文字假借、衍脱錯簡而妄加妄删妄改，繼言誤倒衍脱而失其韻，大較爲四類。」（同上第1016行）

## I 自述

动手改字之前，先要**定性"这错是怎么来的"**。王氏把一切古书讹误归为两大来源：**传写讹脱**（抄手无意的形近、脱、衍、倒、错简）与**凭意妄改**（后人自觉/不自觉地按己意增删改）。统计上"各半"——所以拿到一处扞格，第一步不是想"怎么改"，而是想"它属于哪一半"。

二分之后，再用**六十二例类型学**对号入座：先分四大类（字形讹误／衍脱错简／妄改妄加妄删／韵文失韵），再下探具体类型（因字不习见而误、因假借而误、因隶草俗古字而误、两字误一字、旁记阑入、既误又妄改、改字以合韵而反失其韵……）。每一类对应一套取证方法：**传写讹脱**靠异文、形近、文例对校；**凭意妄改**须还原古貌（古制、古音、本书自例），绝不能"据彼改此"顺着妄改再改。这张卡是可操作的**诊断决策树**——先定性再分类，据此分派取证路径。

## A1 书中案例

1. **问题**：《管子》"内纵于美色淫声"与"驰骋田猎"对举，今本"淫"显乖。→**方法**：定性为**凭意妄改**（后人依"淫声"常语改"音"）；查宋本、朱本作"美好音声"，且"美好音声"对"驰骋田猎"四字对四字。→**结论**：今本"美色淫声"为妄改。→**结果**：校作"美好音声"，异文＋对文双证。（c14，妄改类）

2. **问题**：《汉书》"顺之和起，逆之害生"，"和"与"害"不儷。→**方法**：定性为**传写讹脱**（草书形误）；"顺逆""利害"对文，查《文选》注引作"利"。→**结论**："和"为"利"草误。→**结果**：改"和"为"利"。（c12，字形讹误类）

3. **问题**：《淮南·说山》"山有猛兽……故国有贤臣，折冲千里"，"里"与"采"失韵，脉络隔断。→**方法**：定性为**错简而失其韵**（六十二例之一）；各本"故国有贤臣"二句错简在"形劳则神乱"下，既隔脉络又破韵。→**结论**：错简移位。→**结果**：移回复位。（c24，错简失韵类）

## A2 未来触发

当用户面对以下情境时启用：
- 已确认文本有误（经 CAP-01 闸门、CAP-02 排查），需要判断"这处错属于什么类型、该用哪种取证法"。
- 收到以讹传讹的网络古文/复制粘贴文本，要正确修复而非乱下刀。
- 区分"OCR/转录失真（传写类）"与"后人润色（妄改类）"以决定补正还是还原。
- 校到一处新讹字无从下手，需要快速锁定取证路径。

**语言信号（中英 key triggers）**：
- 中文：「这是什么类型的错」「是传抄还是后人改的」「OCR错还是妄改」「怎么归类」「致误之由」「错简/衍文/脱文/形误」
- 英文：`what kind of error` / `scribal vs. deliberate emendation` / `textual corruption type` / `transposition / haplography / dittography` / `diagnose the corruption`

**与相邻能力的区分（初稿）**：本卡只做"定性＋分类"，不替代具体取证。传写类的"形近"细节归隶草字形讹混（CF-18），"失韵"归失韵校验（CF-04），"对文"归文例互证（CF-03），"以声破假借"归以声求义（CF-01），"注正双误"归旧注批判（CAP-07）。本卡输出"这是X类错→应查Y证据"，再交棒下游。

## E 执行步骤（诊断决策树）

**步骤 1 — 二分定性：传写讹脱 vs. 凭意妄改**
- 动作：问两问——(a) 有无异文/类书支持原字？（有→偏传写）(b) 改动是否"顺今/常之笔"、是否按后起常识润色？（是→偏妄改）
- 完成标准：将讹误归入两大来源之一，并简述理由。
- 判停点：若两类证据矛盾（如定为形误却无类书支持且改后更顺），回到二分重判。

**步骤 2 — 对号六十二例（四大类下探）**
- 动作：依定性进入大类，命中对号的具体类型：
  - 字形讹误：因字不习见／假借／古字／隶书／草书／俗书而误；两字误一字；误字与本字并存；旁记阑入。
  - 衍脱错简：衍至数字／脱数十字／误而兼脱／正文注文互窜／错简。
  - 妄改妄加妄删：不审文义／因字不习见／不识假借而妄改、妄加、妄删、颠倒；既误而又妄改等二十八例。
  - 韵文失韵：因误／脱／倒／改字而失韵，改字以合韵而实非韵、反失其韵等十八例。
- 完成标准：给出**具体类型名**（如"草书形误""既误而又妄改""错简而失其韵"）。

**步骤 3 — 据类型分派取证**
- 动作：传写类→查异文、形近对手集、本书文例；妄改类→还原古貌（古制/古音/本书自例），**不据彼改此**；失韵类→依古音部类核校。
- 完成标准：取证路径与所定类型一一对应，且证据可操作（能列出要查的文献/音韵/文例）。

## B 边界

- **反场景**：文本本通、只是用户训诂不足——此时不该"推致误之由"，而该补古义（转 CAP-02 第三层）。已确知是单纯假借而非讹字时，归以声求义（CF-01），不必套类型。
- **书中警告的失败模式**：
  - 不先定性就动手：底本已显讹误仍就误文再改，误之又误（x11：《藏》本"扢"误"粉"，刘本又改"于摩"为"摩磨"）。
  - 误字沿入字书韵书，以"权威"证讹（x12：杨慎《古音余》、吴氏《字汇补》收讹字"晽""莣"）。
  - 既改正文又改注以自圆，注中残留原字反成铁证（x13~x15：刘绩改"干越"为"于越"并改高注）。
- **阶段 0 批判所得的王氏盲点**：
  - **六十二例专就《淮南》、道光元年前所作**，不能尽括《杂志》全部讹例（序文已自承）；溢出者须另立类。
  - **类书引文本身有讹**：群书所引未必存古本之旧，据类书定类型可能误判。
  - **理校盖然性**：定性仍是推测，非定谳。
  - **银雀山简十中有一失**：理校非百发百中，定性存疑比妄断稳。
