# 决策规则速查 — 读书杂志（八十二卷·余编二卷）

| 能力 | 一句话规则 |
|---|---|
| 理证总程序：改字四道闸门与证据不全不动手 | 读不通先过四道闸门（对文/句法/古韵/异文注证），五重证据未三路交汇则存疑不动手。 |
| 读不通排查序：先疑文本、次疑旧注、最后疑己 | 读不通先疑文本、次疑旧注、最后才疑己——反转常人"疑己"的本能顺序。 |
| 推致误之由：致误二分与六十二例类型学 | 先定"传写讹脱"还是"凭意妄改"，再对号六十二例类型，据此分派取证路径。 |
| 以声求义破假借（含古音部类审定） | 字义不通先查古音通假、读破不轻改字；今音近≠古通，须以韵部声纽双证。 |
| 文例互证：对文·平列·相对为文·字数齐一 | 句法对称（对文/平列/字数齐一）即证据——不对文处多为讹脱衍倒。 |
| 失韵校验与合韵陷阱 | 失韵即可疑；改字以合韵而实非韵/反失韵是妄改重灾区——须用古音判协。 |
| 旧注批判与注正双误反推 | 旧注既是反推原貌的时间胶囊，也是"注正双误"的妄改红旗——用上下文/韵/文例三把尺检验，不盲从权威。 |
| 连语不可分训（古人自有複语） | 二字叠用同义/双声叠韵即连语，整体训释不可分拆；拆分即注家望文生义之失。 |
| 虚词语义推勘（转语词·发语词·反训） | 虚词优先走音转与反训，勿改实词迁就；来=往、乱=治、故=今皆反训。 |
| 以今律古／不据彼改此（历史语境还原） | 本书自例自足——后人依他书/俗本/今制妄改须还原历史语境，不据彼改此。 |
| 语境致误诊断：蒙上而衍·涉下而误·重文相乱 | 见某字与上下句同形即疑语境致误——蒙上而衍/涉下而误/重文相乱，删之须验异本。 |
| 旁记误合与二本并录 | 遇"AB怪字"或叠赘，拆回两源异文（旁记阑入/二本并录），据文义音韵剔其一。 |
| 错误繁殖链追踪与斩链溯源 | 遇"改了还不通/须连带改注"的乱象，溯初误斩链，不在下游补丁上再下刀。 |
| 隶草字形讹混推因（重建讹变链） | 形近致讹须还原讹变链（篆→隶→草→俗），枚举形近对手集＋文义音韵筛正字。 |
| 增字为解乱真（需增字方通者多半文本有误） | 凡需增字方通者多半文本有误；注家所增之字恰是原文脱讹的反向证据。 |
| 古历二法（数字历法须核古制，不得以今法改古） | 数字历法须核古制——古历建寅/建子二法并存，不得以今法改古。 |
| 他书引文甄伪与书证分级 | 他书引文与类书异文并非皆存古本之旧，须按未改之引/刻本已改/改而未净三档分级，并警惕点校本与今古文系统追改污染后再采信。 |
| 后人妄改七型与追改层位归档 | 判后人追改七型动机，按改字痕迹存活度五档归档，两问必答（原文当作某+今本何以成此）方定案。 |
| 定案文书范式与定案强度分级 | 上游判完改不改，本卡管结论怎么写、标哪级强度（铁案/稳案/疑案/阙疑）、正文与校记如何分置。 |
| 名物·地理·事理校验 | 叙事字面通顺却与名物制度/地理方位/物理事理冲突时靠内容真实性定讹；事理语感只辅助，须另配一路证据方可立案。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
