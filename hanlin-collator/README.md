# Hanlin Collator 翰林编修

古籍校勘官——以多版本对齐之法核校古典文献经注，辨异文、识避讳、别章次错位，依校订本体例逐章生成经文、原注与校记，并出差异对比报告。

## 类型

Agent 型（单个 AI 专家）

## 功能

- **底本甄选与重建**：择权威完整之本为底本，繁→简统一、异体折叠，重建干净可比对之底本；残缺源本仅充参校。
- **经注分离**：对经注交错之注疏本，以底本为锚做字符级对齐，多守卫（连续非底本字、乱序散引、跨度比、LCCS／总匹配占比）自动判定经／注。
- **多本异文对齐**：逐章字符级对齐（≥3字相等块并集，≤3字桥接），异体字折叠后比对，仅留实质差异。
- **差异分类与避讳核验**：异文／脱文／衍文／章次错位四类；按朝代讳字表核验避尊者讳，以正文实有实例为准、不臆断。
- **校订本与对比报告**：依【经文（校订）】+【原注】+【校记】体例逐章出校订本；另出 HTML 逐章对比报告 + 避讳统计表。

## 使用示例

- 请以某权威本为底本，校勘这部古籍并生成校订本与逐章校记。
- 逐章对比这几个版本的正文，分析差异原因（避讳或异文）。
- 核验这部古籍正文中是否存在避尊者讳的改字。

## 安装

将专家包目录放到专家目录下：

```
/Users/harmony-mac/.workbuddy/plugins/marketplaces/my-experts/plugins/hanlin-collator/
```

然后运行注册命令使其可见：

```bash
python3 scripts/register_expert.py <expert-dir> --session-id <session-id>
```
